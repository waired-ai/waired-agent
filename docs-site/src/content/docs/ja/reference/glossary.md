## <a id="words-you-meet-while-setting-up"></a>セットアップ中に出会う言葉

<a id="waired-app"></a>
**Wairedアプリ**: macOSではメニューバー、WindowsとLinuxでは時計のとなりにあるアイコンです。メニュー1つで、画面のあるパソコンで日常的にWairedを使う手段です。[Wairedアプリの基本](/ja/getting-started/meet-the-app/)を参照してください。

<a id="background-service"></a>
**バックグラウンドサービス**: このパソコンを接続し続け、推論エンジンを動かすWairedの部分です。誰かがログインする前に、パソコンの起動時に始まります。エラーメッセージでは`waired-agent`と呼ばれます。

<a id="sign-in"></a>
**サインイン**: Googleでサインインすると、このパソコンが自分のプライベートネットワークに加わります。同じGoogleアカウントでサインインしたパソコンはどれも、互いに届きます。

<a id="your-network"></a>
**自分のネットワーク**: 自分のパソコンどうしをつなぐ、プライベートで暗号化された接続です。ほかの誰も参加できず、公開のインターネットからは届きません。

<a id="device"></a>
**デバイス**: ネットワーク上の1台のパソコンです。デスクトップ、ノートパソコン、職場のマシンは3台のデバイスです。

<a id="administrator-rights"></a>
**管理者権限**: 自分のアカウントだけでなく、パソコン全体を変更する権限です。Wairedは、バックグラウンドサービスと推論エンジンのインストールに必要とします。macOSとLinuxでは`sudo`がそれにあたります。Windowsでは「このアプリがデバイスに変更を加えることを許可しますか?」のウィンドウです。

<a id="auth-key"></a>
**認証キー**: サーバーやコンテナがブラウザなしでネットワークに加わるためのパスワードです。Webコンソールで作成します。[認証キーでサーバーをセットアップする](/ja/getting-started/servers-and-auth-keys/)を参照してください。

<a id="web-console"></a>
**Webコンソール**: [app.waired.ai](https://app.waired.ai)です。ネットワーク上のすべてのパソコンを見て、パソコンをまたぐ設定を変えます。Wairedアプリでは［Open Waired console…］から開きます。

## <a id="models-and-inference"></a>モデルと推論

<a id="model"></a>
**モデル**: 大規模言語モデルです。重みは、学習したパラメーターの数GBのファイルです。`qwen3.8-27b`はモデルです。大きいモデルほど答えの品質は上がり、必要なメモリも増えます。

<a id="inference"></a>
**推論**: モデルから答えを生成することです。「このパソコンで推論を動かす」とは、答えがここで計算されることです。

<a id="inference-engine"></a>
**推論エンジン**: モデルをメモリに読み込んで動かすプログラムです。Wairedは[Ollama](https://ollama.com)を、NVIDIAまたはAMDのGPUを持つLinuxのサーバーではvLLMを、インストールして管理します。

<a id="memory-vram"></a>
**メモリとVRAM** : モデルは、動くためにメモリに収まる必要があります。単体のGPUを持つパソコンでは、GPU自身のメモリであるVRAMです。Appleシリコンと一部のAMDのチップでは、メモリはプロセッサとグラフィックス側で共有されるので、全体が対象です。

<a id="toks"></a>
**tok/s（1秒あたりのトークン数）**: 答えが出てくる速さです。トークンは、おおよそ単語の4分の3です。

<a id="context-window"></a>
**コンテキストウィンドウ**: モデルが一度に考慮できる会話の長さです。ローカルのモデルはクラウドのモデルよりウィンドウが短いので、Claude Codeの長いセッションは収まるように要約されます。これは正常です。

<a id="llm"></a>
**LLM** : 大規模言語モデルで、Wairedが動かすモデルの種類です。このドキュメントの「モデル」は常にLLMを指します。

<a id="weights"></a>
**重み**: モデルを構成する学習済みのパラメーターで、1つまたは複数の大きなファイルとして保存されます。「モデルをダウンロードする」とは重みをダウンロードすることで、「モデルが載っている」とは重みがメモリにあることです。

<a id="kv-cache"></a>
**KVキャッシュ**: モデルがリクエストを処理する間に使うメモリで、それまでの会話の1トークンごとに1項目です。コンテキストウィンドウとともに増えるので、モデルに必要なメモリは重みの大きさより多くなります。

<a id="quantization"></a>
**量子化とvariant** : 重みを低い精度で保存したモデルのビルドで、たとえば4ビットの`q4`のGGUFファイルです。必要なメモリが減ります。カタログは各モデルのvariantを推論エンジンごとに載せています。「no Ollama variant」は、カタログにOllamaが読み込めるそのモデルのビルドがないことを意味します。

<a id="ttft"></a>
**最初のトークンまでの時間（TTFT）**: 答えの最初の単語が表示されるまでにリクエストが待つ時間です。重みがメモリになければその読み込みと、プロンプトの読み取りを含みます。`waired status`では`first token:`として表示されます。

<a id="keep-alive"></a>
**keep-alive** : 最後のリクエストのあと、推論エンジンがモデルを載せたままにする時間です。［Always］は降ろしません。時間を設定するとメモリが解放され、次のリクエストで重みを読み込み直す代償を払います。

<a id="unified-memory"></a>
**ユニファイドメモリ**: Appleシリコンや一部のAMDのチップのように、プロセッサとGPUが共有する1つのメモリです。VRAMという別の値はなく、全体をモデルが使えます。

<a id="benchmark"></a>
**ベンチマーク**: このパソコンがモデルでどれだけ速く答えるかをWairedが計測することです。セットアップの最後と、`waired runtimes benchmark`を実行したときに行われます。

## <a id="words-you-meet-when-using-it-from-another-computer"></a>別のパソコンから使うときに出会う言葉

<a id="direct-connection"></a>
**直接接続**: 2台のパソコンがインターネットを越えて直接、エンドツーエンドで暗号化して通信することです。通常はこの形です。

<a id="relay"></a>
**リレー**: ファイアウォールやルーターが直接接続を阻む場合、通信は代わりにWairedのサーバーを経由します。それでもエンドツーエンドで暗号化されていて、リレーは読めないデータをそのまま受け渡します。

<a id="mesh"></a>
**メッシュ**: 自分のデバイスどうしが作るプライベートネットワークです。中央のハブを介さず、どのデバイスもほかのすべてのデバイスに直接届きます。このドキュメントでは初出で「Wairedメッシュ」と書きます。

<a id="overlay"></a>
**オーバーレイネットワーク**: 既存のインターネット接続の上に作るプライベートネットワークです。ルーターやWi-Fiの設定は何も変わりません。

<a id="peer"></a>
**ピア**: いま使っているデバイスから見た、メッシュ上のほかのデバイスです。`waired peers list`が名前を表示します。このドキュメントでは初出で「ピアデバイス」と書きます。

<a id="sharing"></a>
**共有**: このパソコンを貸し出すかどうかで、パソコン側にある唯一のスイッチです。オフにすると全員への提供が一度に止まります。共有するパソコンを誰に提供するかはWebコンソールで設定します。[自分の別のパソコンと共有する](/ja/guides/sharing/)を参照してください。

<a id="capacity"></a>
**処理能力**: パソコンが同時に処理するリクエストの数で、Webコンソールで［Max concurrent requests］として設定します。並行スロットごとにVRAMを確保します。

<a id="pausing"></a>
**一時停止**: アンインストールも設定の変更もせずに、このパソコンでWairedがあらゆる処理を扱うのを一時的に止めることです。`waired resume`で戻します。

<a id="public-share"></a>
**パブリック共有**: 自分のモデルをアカウント外の人に提供し、相手のモデルを使えるようにする、自分で選んで有効にする機能です。既定ではオフで、Webコンソールで切り替えます。[パブリック共有](/ja/public-share/)を参照してください。

## <a id="words-for-the-coding-tool-setup"></a>コーディングツール連携の言葉

<a id="coding-agent"></a>
**コーディングエージェント**: Claude Code、OpenCode、OpenClawなど、コードを書いたり編集したりするツールです。製品の出力が「コーディングツール」と言っている場合、このドキュメントはそれをそのまま引用します。

<a id="routing"></a>
**ルーティング**: リクエストにどのパソコンが答えるかです。自分のパソコンの間では`waired worker`が決めます。Claude Codeのターンが自分のパソコンに行くかAnthropicに行くかは、`/model`で選んだモデルだけで決まります。

<a id="status-line"></a>
**ステータス行**: WairedがClaude Codeのフッターに加える表示で、このセッションのターンの実行先と、直前のターンに答えたモデルを示します。[Wairedのステータス行](/ja/guides/claude-code/status-line/)を参照してください。

<a id="falling-back"></a>
**フォールバック**: リクエストのためにWairedが選んだパソコンが結局処理できなかったとき、Wairedはリクエストを自分の別のパソコンに送り、そのことを記録します。Wairedアプリの［Recent activity］に一覧が表示されます。クラウドを意味することはありません。自分のパソコンのどれも答えられないWairedの行のClaude Codeのターンは、失敗してそのことを表示します。

<a id="notice"></a>
**お知らせ**: このパソコンについてWairedが表示するメッセージで、Wairedアプリの行、`waired status`、`waired doctor`に表示されます。事実である間だけ表示されます。[お知らせ](/ja/guides/notices/)を参照してください。

## <a id="words-you-may-see-in-error-messages"></a>エラーメッセージで見かける言葉

<a id="waired-agent"></a>
**Wairedエージェント**: バックグラウンドサービスです。「waired-agent is not running」は、それが止まったことを意味します。再起動するか、`waired doctor`を実行します。

<a id="gateway"></a>
**ゲートウェイ**: コーディングツールやチャットアプリがリクエストを送る、自分のパソコン上のローカルなアドレス（`127.0.0.1:…`）です。答えが自分の別のデバイスから来る場合を除き、パソコンの外には出ません。

<a id="worker"></a>
**ワーカー**: リクエストに答えるパソコンです。Wairedアプリには［Worker: `<name>`］として表示されるので、自分のどのパソコンが処理しているかが分かります。

<a id="control-plane"></a>
**コントロールプレーン**: 自分のデバイスどうしが互いを見つける方法を伝える、Wairedが運用するサービスです。扱うのはサインイン、デバイスの一覧、Network Mapだけです。プロンプトと答えがここを通ることはありません。`waired status`では`Control Plane:`として表示されます。[プライバシー：パソコンの外に出るもの](/ja/concepts/privacy/)を参照してください。

<a id="coordination-service"></a>
**調整サービス**: このドキュメントの以前の版で[コントロールプレーン](#control-plane)を指していた古い名前です。2つの名前は同じものを指します。

<a id="network-map"></a>
**Network Map** : ネットワーク上のデバイスの署名付きの一覧で、公開鍵、アドレス、リレーのURLを含みます。コントロールプレーンが各デバイスに送り、デバイスどうしが互いを見つけて信頼できるようにします。
