## セットアップ中に出てくる言葉

<a id="waired-app"></a>
**Waired アプリ**
: インストーラーが入れる 2 つのもの。常時つながっている常駐サービスと、
  入力する `waired` コマンドです。ふだんは Waired アイコン（macOS はメニューバー、Windows・Linux は時計のとなり）で操作します。

<a id="sign-in"></a>
**サインイン（登録）**
: Google でサインインすると、このパソコンがあなたの専用ネットワークに加わります。
  **同じ** Google アカウントでサインインしたパソコンどうしが、互いにつながります。

<a id="your-network"></a>
**あなたのネットワーク**
: あなた自身のパソコンどうしをつなぐ、暗号化された専用の通信路です。
  他人は参加できず、インターネット側からも見えません。

<a id="device"></a>
**デバイス**
: ネットワークに参加しているパソコン 1 台のこと。デスクトップ・ノート・仕事用の
  3 台なら、デバイスは 3 つです。

<a id="administrator-rights"></a>
**管理者権限**
: 自分のアカウントだけでなく、パソコン全体の設定を変更できる権限。
  Waired は、電源投入時から動く常駐サービスを入れるために最初の 1 回だけ必要とします。
  macOS / Linux では `sudo`、Windows では「このアプリがデバイスに変更を加えることを
  許可しますか？」の青い画面がこれにあたります。

## モデルと推論に関する言葉

<a id="model"></a>
**モデル**
: 大規模言語モデル（LLM）。その重みは学習結果が詰まった数 GB のファイルです（例: `qwen3.8-27b`）。
  大きいほど回答の質は上がり、必要なメモリも増えます。

<a id="inference"></a>
**推論（inference）**
: モデルを使って回答を作る処理そのもの。「このパソコンで推論する」とは、
  回答をこのパソコンの中で計算する、という意味です。

<a id="inference-engine"></a>
**推論エンジン**
: モデルをメモリに読み込んで動かすプログラム。Waired が
  [Ollama](https://ollama.com) を自動で導入・管理します。

<a id="memory-vram"></a>
**メモリ / VRAM**
: モデルはメモリに収まらないと動きません。GPUを積んだパソコンでは
  その専用メモリ（**VRAM**）が対象です。Apple Silicon や一部の AMD チップでは
  CPU と GPU がメモリを共有する（ユニファイドメモリ）ため、全体が対象になります。

<a id="toks"></a>
**tok/s（1 秒あたりトークン数）**
: 回答が出てくる速さ。1 トークンはおよそ単語 0.75 個分です。
  15 tok/s を下回るあたりから、コーディング用途では体感的に遅くなります。

<a id="context-window"></a>
**コンテキストウィンドウ**
: モデルが一度に考慮できる会話の量。ローカルのモデルはクラウドのモデルより小さいため、
  長い Claude Code のセッションでは自動的に要約されます。これは正常な動作で、
  回答の内容が失われるわけではありません。

<a id="llm"></a>
**LLM**
: 大規模言語モデル（large language model）。Waired が動かすモデルの種類で、
  このドキュメントで「モデル」と言えば常に LLM を指します。

<a id="weights"></a>
**重み（weights）**
: モデルを構成する学習済みパラメータ。1 つまたは複数の大きなファイルとして保存され
  ます。「モデルをダウンロードする」は重みをダウンロードすること、「モデルが
  載っている」は重みがメモリにあることです。

<a id="kv-cache"></a>
**KV キャッシュ**
: モデルがリクエストを処理する間に使うメモリ。ここまでの会話のトークン 1 つにつき
  1 エントリ持つため、コンテキストウィンドウに比例して増えます。モデルに*必要な*
  メモリが重みのサイズより大きいのはこのためです。

<a id="quantization"></a>
**量子化 / variant**
: 重みを低い精度（例: 4 bit、`q4` の GGUF ファイル）で保存し、必要なメモリを減らした
  モデルのビルド。カタログには推論エンジンごとの variant が載っており、
  「no Ollama variant」は Ollama が読み込めるビルドがカタログに無いという意味です。

<a id="ttft"></a>
**最初のトークンまでの時間（TTFT）**
: リクエストを送ってから回答の最初の語が出るまでの時間。重みがメモリに無ければその
  読み込み、そしてプロンプトの読み取り（prefill）を含みます。`waired status` では
  `first token:` の行に出ます。

<a id="keep-alive"></a>
**keep-alive**
: 最後のリクエストの後、推論エンジンがモデルをメモリに残しておく時間。**Always** は
  降ろしません。時間が来るとメモリを解放し、次のリクエストは重みの読み込みから
  やり直します。

<a id="unified-memory"></a>
**ユニファイドメモリ**
: CPU と GPU が 1 つのメモリを共有する構成（Apple Silicon や一部の AMD チップ）。
  VRAM という別の数字は無く、プール全体がモデルに使えます。

## ほかのパソコンから使うときの言葉

<a id="direct-connection"></a>
**直接接続**
: 2 台のパソコンがインターネット越しに直接つながり、端から端まで暗号化された状態で
  通信します。通常はこちらになります。

<a id="relay"></a>
**リレー（中継）**
: ファイアウォールやルーターの都合で直接つながらないとき、Waired のサーバーを経由します。
  暗号化はそのままなので、中継サーバーは中身を読めません。

<a id="mesh"></a>
**メッシュ**
: あなたのデバイスどうしが互いに直接つながって作る専用ネットワーク。中央のハブは
  ありません。アプリのメニューでは mesh（**Share engine to mesh**）と表示されます。
  各ページの初出では「Waired メッシュ」と書きます。

<a id="overlay"></a>
**オーバーレイネットワーク**
: 既存のインターネット接続の上に重ねて作る専用ネットワーク。Waired のメッシュも
  その一つです。ルーターや Wi-Fi の設定は何も変わらず、自分のデバイス間の暗号化
  リンクだけで構成されます。

<a id="peer"></a>
**ピア**
: いま使っているデバイスから見た、メッシュ内のほかのデバイス。`waired peers list`
  で一覧できます。各ページの初出では「ピアデバイス」と書きます。

<a id="sharing"></a>
**共有**
: このパソコンの AI を、**自分のほかの端末**から使えるようにするかどうかの設定。
  ノートパソコンから使いたいデスクトップでは有効に、このパソコン専用にしたい場合は無効にします。

<a id="pausing"></a>
**一時停止**
: アンインストールや設定変更をせずに、このパソコンでの Waired の処理を一時的に止めること。
  `waired resume` で元に戻ります。

<a id="public-share"></a>
**パブリック共有**
: 自分のアカウント外の人にも AI を提供する、任意参加の別機能です。既定では無効。
  [パブリック共有](/ja/public-share/)を参照してください。

## コーディングツール連携の言葉

<a id="coding-agent"></a>
**コーディングエージェント**
: Claude Code、OpenCode、OpenClaw など、コードを書いたり直したりしてくれるツール。

<a id="routing"></a>
**ルーティング（振り分け）**
: その質問にどの AI が答えるか — このパソコン、自分の別のパソコン、あるいはクラウド。
  `waired claude route` で確認・変更できます。

<a id="falling-back"></a>
**フォールバック**
: 自分のモデルが答えられないとき（ダウンロード中・メモリ不足・スリープ中など）、
  Claude Code が本来の Anthropic API を使って処理を続けること。
  Waired はこれを隠さず、必ず表示します。

## エラーメッセージで見かける言葉

<a id="waired-agent"></a>
**waired-agent（デーモン）**
: 常駐サービスのこと。`waired-agent is not running` は停止している状態です。
  サービスを再起動するか、`waired doctor` を実行してください。

<a id="gateway"></a>
**ゲートウェイ**
: コーディングツールがリクエストを送る、パソコン内部のアドレス（`127.0.0.1:...`）。
  自分の別のパソコンで処理する場合を除き、通信はこのパソコンの外に出ません。

<a id="worker"></a>
**ワーカー**
: リクエストに実際に答えるコンピューター。Waired アイコンには
  **Worker: `<名前>`** と表示され、どのマシンが処理しているかが分かります。

<a id="control-plane"></a>
**コントロールプレーン**
: 端末どうしが互いを見つけられるようにする、Waired 運営のサービス。
  サインイン・デバイス一覧・Network Map だけを扱い、質問と回答の中身は一切
  通りません。`waired status` では `Control Plane:` の行に出ます。
  [プライバシー](/ja/concepts/privacy/)を参照してください。

<a id="coordination-service"></a>
**コーディネーションサービス**
: 以前のページで使っていた[コントロールプレーン](#control-plane)の旧称。
  2 つの名前は同じものを指します。

<a id="network-map"></a>
**Network Map**
: ネットワーク上のデバイスの署名済み一覧 — 公開鍵・アドレス・リレー URL を含み、
  コントロールプレーンが各デバイスに送ることで、互いを見つけて信頼できるように
  します。
