## <a id="the-full-list-of-changes"></a>変更点の一覧

すべてのリリースとその変更点は、GitHubで公開しています。

**[github.com/waired-ai/waired-agent/releases](https://github.com/waired-ai/waired-agent/releases)**

このページが正式な情報源です。各項目にはバージョン、日付、修正または追加された
内容が書かれ、各プラットフォーム向けのインストーラが添付されています。

## <a id="stable-and-edge"></a>stableとedge

| チャンネル | 内容 | 対象 |
|---|---|---|
| **stable** | 番号付きのリリースを順に追います。既定です。Wairedがプレリリースの間は、リリース候補版がこれにあたります。 | 全員。 |
| **edge** | 何かがマージされるたびに、最新のソースからビルドされます。 | リリース前に修正を使いたい人で、多少の不安定さを気にしない人。 |

切り替えるには次のように実行します。

```sh
waired update --edge      # edgeに移る
waired update --stable    # 戻す
```

<Aside type="caution" title="edgeはリリースと同じようにはテストされていません">
	すべてのedgeビルドは自動の検査を通っていますが、リリースはさらに3つのOSの
	実機でインストールと推論のテストを受けます。頼りにしているパソコンでは
	stableのままにしてください。
</Aside>

## <a id="keeping-up-to-date"></a>最新に保つ

```sh
waired update --check     # 新しいものがあるか
waired update             # インストールする
```

更新があると、Wairedアプリのメニュー上部にお知らせが表示されます。
[Wairedをアップデートする](/ja/getting-started/update/)を参照してください。

<Aside type="note" title="このドキュメントにあるものが手元にない場合">
	先にアップデートしてから、ページを読み直してください。アップデートしても
	一致しない場合は、ドキュメントの不具合です。ページのアドレスと
	`waired version`の出力を添えて[issueを立てて](https://github.com/waired-ai/waired-agent/issues)
	ください。
</Aside>
