どのノートパソコンからClaude Codeに入力しても、答えは自分の持っているパソコンから返ってきます。メッセージごとの課金もサブスクリプションもなく、プロンプトは自分の端末の外に出ません。

## 選ばれている理由

<CardGrid>
	<IconLinkCard title="コマンド1つ" icon="rocket" href="/ja/quickstart/">
		1行でインストールし、Googleでサインインして、ブラウザかターミナルで仕上げます。どちらでも約10分です。
	</IconLinkCard>
	<IconLinkCard title="費用がかからない" icon="approve-check" href="/ja/reference/model-catalog/">
		モデルはすでに持っているハードウェアで動きます。最近のプロセッサで十分で、GPUがあれば速くなります。自分のパソコンに収まるモデルを確認できます。
	</IconLinkCard>
	<IconLinkCard title="既定でプライベート" icon="padlock" href="/ja/concepts/privacy/">
		端末どうしが、エンドツーエンドで暗号化された経路で直接通信します。Waired自身のサーバーがプロンプトや答えを見ることはありません。
	</IconLinkCard>
	<IconLinkCard title="ツールはそのまま" icon="puzzle" href="/ja/guides/claude-code/">
		Claude Code、OpenCode、OpenClaw、OpenAI互換のクライアントはそのまま動きます。変わるのは、答えがどこから来るかだけです。
	</IconLinkCard>
</CardGrid>

## コマンド1つでインストール

<Tabs syncKey="os">
	<TabItem label="Windows">
		スタートボタンを右クリックして開く［ターミナル（管理者）］で実行します。

		```powershell
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/install.ps1 | iex
		```
	</TabItem>
	<TabItem label="macOS">
		⌘＋スペースで`ターミナル`と入力して開く**ターミナル**で実行します。

		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
		```
	</TabItem>
	<TabItem label="Linux">
		Ubuntu 24.04以降、またはDebian trixie以降のターミナルで実行します。

		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
		```
	</TabItem>
</Tabs>

インストーラは、これから行う内容を表示し、何かを変更する前に確認します。そのあとはブラウザかターミナルでセットアップを仕上げます。どちらの手順も[クイックスタート](/ja/quickstart/)にあります。
