既定では、Wairedはプロンプトと答えを自分の端末の中にとどめます。それを超える
もの、つまりチーム、公開ノード、クラウドのAPIは、それぞれ同意の手順を伴う明示的な
選択です。黙って共有されることはありません。

## <a id="your-data-path"></a>データの経路

自分の端末が別の端末のモデルを使うとき、リクエストは2台の間をエンドツーエンドで
暗号化されたWireGuardの経路で直接移動します。Wairedがホストするサービスは
通りません。

- **コントロールプレーン**は、自分のパソコンどうしが互いを見つけられるようにします。
  署名されたNetwork Mapで公開鍵とエンドポイントを配ります。プロンプトや答えを
  受け取ることはありません。
- **リレー**は、直接接続できないときにだけ使われ、暗号化されたWireGuardのパケットを
  転送します。復号することはできません。

要するに、コントロールプレーンが鍵を配り、会話は自分の端末どうしで直接行われます。

## <a id="sharing-beyond-your-own-devices"></a>自分の端末の外との共有

リクエストが実行される場所は3つあります。外へ向かう各段階は、それぞれ同意の手順を
伴う別々の選択で、すぐにオフにできます。

- **自分の端末。** 既定です。リクエストは自分のアカウントでサインインしたパソコン
  でだけ実行されます。
- **チーム。** チームに参加した場合です。リクエストはチームメイトのパソコンでも
  実行されることがあり、相手には本名で表示されます。自分の所有でないパソコンに
  共通する注意が当てはまります。その所有者は、送った内容を見られます。
- **公開ノード。** パブリック共有を有効にした場合です。リクエストは見知らぬ人が
  共有するパソコンで実行されることがあり、相手には固定のニックネームだけが
  見えます。相手に見えるものと見えないもの、自分が持つすべてのコントロールは
  [パブリック共有](/ja/public-share/)を参照してください。

## <a id="what-reaches-anthropic"></a>Anthropicに届くもの

Claude Codeの連携が書き込む設定は`ANTHROPIC_BASE_URL`の1つで、Claude Codeの
リクエストがこのパソコンのWairedを通るようにします。Wairedがclaude.aiの資格情報を
保存したり利用したりすることはありません。Anthropicに届くのは、モデルにAnthropicの
モデルを選んだターンだけで、Wairedがないときと同じように自分のサインインで
届きます。Wairedの行のターンは、自分のパソコンで実行されるか、理由とともに
失敗するかのどちらかで、Anthropicには送られません（プロジェクトの決定記録
`docs/decisions/20260903/0333-no-automatic-crossing-to-or-from-anthropic.md`）。

WairedはAnthropicと提携関係にも承認関係にもありません。また、AnthropicはClaude
CodeからClaude以外のモデルへゲートウェイ経由でルーティングすることをサポート
していません。[Claude Codeから使う](/ja/guides/claude-code/)を参照してください。

## <a id="no-silent-fallback"></a>黙って切り替えることはありません

Wairedが自分の判断でデータをほかの場所へ送ることはなく、クラウドも例外では
ありません。Claude Codeでは、各ターンは`/model`で選んだモデルが指す場所で実行
されます。自分のパソコンがWairedのターンに答えられなければ、ターンは失敗して
理由を伝えます。Anthropicにターンを送るのは、自分でAnthropicのモデルを選ぶこと
だけです。直前のターンの行き先は`waired claude status`に表示されます。

公開ノードやチームへのルーティングも、黙って行われることはありません。自分で
オンにして同意メッセージを受け入れたあとにだけ存在し、現在の状態は
`waired public status`でいつでも確認できます。

## <a id="mixing-your-own-computers-and-the-cloud"></a>自分のパソコンとクラウドを併用する

選択の単位はClaude Codeのセッションです。あるセッションでWairedの行を、別の
セッションでAnthropicのモデルを選ぶと、それぞれ選んだ場所にとどまります。
Anthropicのモデルのセッションが読んだり議論したりした内容は、Wairedがないときと
同じようにAnthropicに送られます。Wairedの行のセッションは自分のハードウェアに
とどまります。1つのセッションの中で両者を混ぜる設定はありません。

## <a id="cost-and-ownership"></a>費用と所有

モデルはすでに持っているハードウェアで動くので、メッセージごとの課金も
サブスクリプションもありません。Wairedのクライアントはオープンソースで、自分の
パソコンで何が動くかを[GitHub](https://github.com/waired-ai/waired)で読めます。
端末どうしを引き合わせるコントロールプレーンが、こちらでホストしている部分です。

## <a id="sharing-controls"></a>共有のコントロール

どのパソコンのモデルを、そのパソコンの外に提供するかは自分で決めます。

- `waired share off`は、パソコンのモデルをそのパソコンだけのものにします。自分の
  ほかのパソコンと公開のゲストへの提供を、その場で止めます。
- [Webコンソール](/ja/guides/web-console/)のパソコンのページにある［Sharing］の
  カードは、共有するパソコンを誰に提供するかを決めます。自分のほかのパソコン、
  アカウント外の人、またはどちらにも提供しない、です。
- `waired pause`は、パソコンをルーティングから完全に外します。
- `waired public use --off`は、自分のリクエストが公開ノードを使うことを止めます。

[自分の別のパソコンと共有する](/ja/guides/sharing/)と
[Wairedを一時停止する](/ja/guides/pause/)を参照してください。
