画面のあるパソコンでは、**Waired アプリがそのまま Waired 本体**です。
このサイトに書かれていることのほとんどは、コマンドを打たずにここから行えます。

## どこにあるか

**Waired アイコン**をクリックします。

| | |
|---|---|
| **macOS** | 画面上部のメニューバー |
| **Windows** | タスクバー右端、**時計のとなり**。見当たらないときは **^**（隠れているアイコンを表示）をクリック |
| **Linux** | 上部または下部バーの、時計のとなり |

<Aside type="note" title="アイコンだけが Waired ではありません">
	Waired はパソコンの起動時に立ち上がる常駐サービスとして動いています。アイコンは

	（→ [終了する](#終了する)）。
</Aside>

## いちばん上の行を読む

最初の 1 行が、ほかのすべての状態を表しています。ここが **Connected** でなければ、
以下の説明どおりには動きません。

| 表示 | 意味 | すること |
|---|---|---|
| **● Connected** | サインイン済みで、到達できる状態。 | 対応不要。 |
| **◐ Connecting…** | 接続中。サインイン直後やスリープ復帰直後に出ます。 | 数秒待ちます。 |
| **○ Not signed in** | インストール済みですが、アカウントが未設定。 | 下の **Sign in…** を選びます。 |
| **◐ Signing in… / ◐ Activating…** | 開始したサインインが進行中。 | 開いたブラウザで完了させます。 |
| **○ Disconnected** | サインイン済みだが、いまネットワークに届いていない。 | **Connect** を選びます。直らなければ[うまくいかないとき](/ja/troubleshooting/)へ。 |
| **◐ Waired agent is starting…** | サインイン直後の正常な状態です。Windows では常駐サービスがアイコンより数分遅れて起動します。 | 待つか、**Start the Waired agent…** ですぐに起動できます。 |
| **⚠ Waired agent is not running** | 起動しているはずの常駐サービスが起動していません。 | **Start the Waired agent…** を選びます（パソコンが管理者の確認を求めます）。[Waired のアイコンに「エージェントが起動していません」と出る](/ja/troubleshooting/#the-waired-icon-says-the-agent-is-not-running)も参照。 |
| **◐ Reconnecting to the Waired agent…** | 常駐サービスは動いていますが、まだ応答がありません。サインインは保たれています。 | 待ってください。通常はすぐ戻ります。 |

## サインインと接続

状態表示のすぐ下の項目は、状況に応じて変わります。

- **Sign in…** — サインインを開始します。Google アカウント選択のためブラウザが開きます。
- **Disconnect** — サインアウトせずに、このパソコンをプライベートネットワークから
  外します。ルーティングが止まるので、しばらくクラウドに戻したいときに使えます。
- **Connect** — 戻します。

<Aside type="caution" title="ここからのサインインだけでは初回セットアップは終わりません">
	新品のパソコンでは、推論エンジンのインストールに管理者権限が必要で、
	アプリ側からはそれを取得できません。未セットアップのパソコンでアイコンから
	サインインすると、セットアップは途中で止まり、ターミナルで `waired init` を
	実行するよう促されます。初回は[クイックスタート](/ja/quickstart/)に従ってください
	（インストーラが一気に通してくれます）。
</Aside>

## Models — 動かす AI を変える

状態表示のすぐ下に**いま動いているモデル**が表示され、**Models** サブメニューに
このパソコンで動かせるモデルが並びます。選ぶと切り替わります。

切り替えは**その場で反映**されます（数秒で読み込み直され、その間もサービスは継続）。
未ダウンロードのモデルを選んだ場合はダウンロードが始まり、完了するまでは
これまでのモデルが応答を続けます。

大きくすべきか小さくすべきかの判断は
[使うモデルを選ぶ](/ja/guides/choose-a-model/)にあります。

## Inference — 推論エンジンそのもの

**Inference** には、**このパソコンで動く** AI の操作がまとまっています。
リクエストの**行き先**は、ひとつ下の **Inference routing** です。

| 項目 | 内容 |
|---|---|
| **Pause / Resume local inference** | このパソコンが AI リクエストに応答するかどうか。停止中でも**ほかの**パソコンの AI は使えます。モデルは**載ったまま**なので再開は一瞬です。 |
| **Run models on this computer** | 同じ切り替えを、まだ一度もモデルを動かしていないパソコン向けに言い換えたもの。リクエストに現実的な時間で答えられないと計測されたマシンでは、Waired はこの状態から始まります。選ぶと推論エンジンとモデルをあわせて導入します。 |
| **Start / Stop inference engine** | 設定を変えずに、いますぐエンジンを止めてメモリ（数 GB）を解放します。再開するとモデルを読み直します。 |
| **Install Ollama…** | 推論エンジンが未導入のときに表示されます。 |
| **Share engine to mesh** | **自分のほかのパソコン**にこのマシンの AI を使わせるかどうか。オフでも自分では使えます。 |
| **Engine: ready / downloading / disabled** | エンジンの状態。**downloading** はモデルのファイルをネットワークから取得中という意味で、メモリに載っているかどうか（次の行）とは別の話です。 |
| **Model: …** | 使っているモデルと、いまメモリに載っているか（**(loaded)** / **(not loaded)**）。載っていればすぐ答えが始まり、載っていなければ読み直してから答えます。処理中はリクエスト数も付きます — **(loaded, serving 2 requests)**。 |
| **Unload model (free memory)** | エンジンは動かしたままモデルのメモリだけを返します。このパソコンは応答を続け、次の質問でモデルを読み直します。返すものが無いときは **Model not loaded** と表示され、選べません。 |
| **Keep-alive: …** | 最後の質問からモデルをメモリに保持する時間。下に **Always** / **15 minutes** / **1 hour** / **8 hours** が並びます。 |

<Aside type="note" title="この 2 行が出ないパソコンもあります">
	推論エンジンが動いている間ずっとモデルを保持するパソコンでは、単独で降ろす
	ものが無く、設定できる時間もありません。押しても何も起きない行を出すより、
	**Unload model** と **Keep-alive** を出さないようにしています。
	そこでメモリを解放する手段は **Stop inference engine** で、モデルの分だけ
	でなくエンジンが確保している分もまとめて返ります。
</Aside>

<Aside type="note" title="Pause と Unload と Stop は別のものです">
	**Pause local inference** は応答を止めるだけで、モデルはメモリに載ったまま
	（再開のコストがゼロ）です。**Unload model** はメモリを返しつつ応答は続けます。
	**Stop inference engine** はその両方（メモリも保持せず、ここでは何も答えない）です。
	数 GB を空けたうえで作業を続けたいなら Unload を選んでください。
</Aside>

<Aside type="tip" title="モデルを載せたままにする理由">
	Waired は一度読み込んだモデルをメモリに保持します。読み直すには、マシンと
	モデルによって約 17 秒から 1 分ほど、最初のトークンが出るまでに余分にかかり、
	その大半は裏で読み直しておいても取り戻せません。そのため既定は **Always**
	です。自動でメモリを返してほしい場合は時間を選んでください。同じ設定は
	コマンドラインの `waired inference residency` でも変更できます。
</Aside>

## Inference routing — どのマシンが答えるか

**Inference routing** は、このパソコンで何か尋ねたときに**どのマシンが答えるか**を
決めます。メニューの先頭に、いまの答え（**Worker:**）と、ほかのパソコンにいま
届くかどうかが出ます。

**Choose automatically** の下では、選んだルールに従って Waired が自動で選びます。

| 選択肢 | 意味 |
|---|---|
| **Auto** | 自前の AI があればそれを使い、なければ自分のほかのパソコンへ。既定値です。 |
| **Local only** | ほかのパソコンは決して使いません。 |
| **Peer preferred** | 自分でも答えられる場合でも、ほかのパソコンを優先します。高速なデスクトップの隣にあるノートパソコンで有効です。 |
| **Peer only** | ほかのパソコンだけを使います。どれも答えられないときは、黙ってここで動かさずにエラーになります。このマシンを空けておきたいときに選びます。 |

**Pin to one peer** の下では、ルールを飛ばして常に特定の 1 台を使えます。一覧から
選び、**(clear pin)** で **Auto** に戻ります。各項目にはパソコン名と、そこで動いて
いるモデルが並びます。どちらからでも選べます。

いま応答できないパソコンは、モデル名の横に理由が出ます — モデルを取得中なら
*(downloading)*、ダウンロードに失敗したなら *(pull failed)*、推論エンジンが落ちて
いるなら *(engine failed)*。理由を答えられないパソコンや、しばらく連絡が取れて
いないパソコンは *(unavailable)* です。いずれの場合も指定はそのまま残り、その 1 台が
戻るまで応答できないだけです。

<Aside type="tip" title="メモリが足りないときは「エンジンを止める」">
	ほかの作業でメモリが苦しいときは **Stop inference engine** で即座に解放できます。
	壊れるものは何もありません — リクエストはほかのパソコンへ回るか、再開するまで待つだけです。
</Aside>

## Public share — 空いているマシンを貸し借りする

**Public share** は、自分でオンにしない限りオフです。中身は 2 つに分かれます。

- **Share this computer publicly** — ほかの Waired ユーザーがこのマシンで処理を走らせられます。
- **Use public computers** — 自分がほかの人のマシンを使えます。*自分のより速いときは自動で使う*
  / *指定したときだけ* / *使わない* から選びます。

どちらもオンにする前に[パブリック共有](/ja/public-share/)を読んでください。要点は
**公開マシンの持ち主は、あなたが送った内容を読める**ということです。機密は送らないでください。
サブメニューの **Privacy & safety…** がそのページを開きます。

## Claude Code — コーディングエージェントの行き先

独立した 2 つのスイッチがあります。

- **Main conversation** — 自分が入力する会話の行き先。
- **Subagents** — 大量のファイル読み取りを担当するサブエージェントの行き先。

それぞれ **Waired**（自分のモデルのみ）、**Anthropic**（本来の API）、
**Auto**（自分を優先し、応答できなければクラウドへ）を選べます。分けるのは実際に有効で、
本体はクラウドで品質を確保しつつ、量の多いサブエージェントの読み取りだけを
自分のハードウェアに残す、という使い方ができます。

選んだ経路が最後に応答できず別のところが答えた場合も、このサブメニューに表示されます。
詳細は [Claude Code から使う](/ja/guides/claude-code/)。

## This device

このパソコンのネットワーク上の名前、Waired アドレス（クリックでコピー）、
所属ネットワーク、そして自分のほかのパソコンの一覧と、それぞれが動かしているもの。

## Open Admin Console…

[Web コンソール](/ja/guides/web-console/)を開きます。端末一覧、セットアップ画面、
パブリック共有の設定、アカウントを、どのブラウザからでも扱えます。

## Settings

| 項目 | 内容 |
|---|---|
| **OpenCode / OpenClaw** | 各コーディングツールが Waired を使う設定になっているか、設定ファイルの場所。これらのファイルは**あなたの**ホームフォルダにあり、アプリはバックグラウンドサービスとしてではなく、あなたとして読み書きします。**Reconfigure** は確認のうえ `waired link opencode`（または `openclaw`）を実行します。 |
| **Recent activity** | 直近 10 分のうち、指定どおりに応答できず別のところが答えた回数。空なのが正常です。 |
| **About Waired** | バージョン情報。 |
| **Start Waired on login** | パソコンにサインインしたときアイコンを表示するかどうか。チェックが入っていれば表示します。オフにしても常駐サービスは止まりません。 |
| **Sign out…** | このパソコンをサインアウトし、識別情報を削除します。ネットワークから外れ、次に使うときは最初からサインインし直しになります。 |

<Aside type="caution" title="Sign out… と Disconnect は別物です">
	**Disconnect** は一時的で、ワンクリックで戻せます。**Sign out…** は識別情報の削除で、
	次にサインインすると**新しい端末として登録**されます。しばらく自分のモデルを使わないだけなら
	**Disconnect** か、[ルーティングの一時停止](/ja/guides/pause/)を使ってください。
</Aside>

## アップデートがあるとき

メニュー上部にインストールを促す行が現れます。クリックすると管理者権限を求めたうえで
その場で更新します（→ [Waired を更新する](/ja/getting-started/update/)）。

**Notify me about updates** はポップアップ通知だけを止めます。メニュー内の行は
どちらの設定でも残るので、更新できなくなることはありません。中断されなくなるだけです。

## 終了する

**Quit** はアイコンを閉じると同時に、このパソコンを片付けます。推論エンジンを止めて
メモリを返し、誰も操作していない間はほかのパソコンから処理が回ってこないようにします。
Waired 自体はバックグラウンドで動き続け、コーディングツールもそのまま使えます
（ほかのパソコンか、クラウドに回ります）。

設定は何も失われません。共有の設定はそのままなので、アイコンを起動し直せば
このパソコンは元どおり AI を提供します。共有をオフにしていたなら、オフのままです。

アイコンを戻すには、アプリ一覧から Waired を起動するか、
（**Start Waired on login** にチェックがあれば）パソコンにサインインし直します。

<Expected tone="bad" title="アイコンがまったく見当たらない">
	Waired は入っているのにアイコンが出ていない状態です。Windows ではまず **^**
	（隠れているアイコン）を確認してください。それ以外は、アプリ一覧から Waired アプリを
	起動します。Mac なら Launchpad の **Waired**、または Spotlight に「Waired」と
	入力します。Linux で、時計のとなりにアイコンを出す仕組みがないデスクトップでは
	拡張機能が必要です → [Linux にインストールする](/ja/getting-started/install/linux/)

	いずれの場合も常駐サービスには影響がありません。ターミナルで `waired status` を実行すれば、
	正常に動いていることが確認できます。
</Expected>
