共有は、[ルーティング](/ja/guides/routing/)の反対側の設定です。ルーティングはこのパソコンがどのパソコンに依頼するかを決めます。共有は、パソコンがほかのパソコンからのリクエストに答えるか、誰に提供するか、同時にどれだけの処理を受けるかを決めます。モデルを動かすパソコンとしてセットアップしたパソコンは、既定で自分のほかのパソコンと共有されます。

## <a id="the-switch-on-the-computer"></a>パソコン側のスイッチ

各パソコンは、自分を貸し出すかどうかのスイッチを1つ持っています。オフにしないかぎりオンです。

<Tabs syncKey="mode">
	<TabItem label="Wairedアプリで">
		**Wairedアイコン**を選択し、［Inference］を開きます。項目は［Share this computer］か［Stop sharing this computer］で、その下の［Sharing:］の行が結果を表示します。［enabled］、［disabled］、アプリが閉じている間の［paused］、スイッチはオンなのにコンソールがこのパソコンをどの提供先からも外している場合の［nobody, set in the console］のいずれかです。
	</TabItem>
	<TabItem label="ターミナルで">
		```sh
		waired share on
		waired share off        # 全員への提供を止める。実行中の処理も打ち切られる
		waired share status
		```

		`status`は全体像を表示します。

		```text
		Sharing this computer: on
		Your other computers: on
		Your team: off
		People outside your account: off
		Who this computer is shared with is set in the Waired console.
		```
	</TabItem>
</Tabs>

スイッチをオフにすると、あらゆる提供がその場で止まります。自分のほかのパソコンは答えてもらえなくなり、アカウント外からこのパソコンを使っている人は切断され、その時点で実行中のリクエストは完了しません。このパソコン自身での利用には影響ありません。Webコンソールからこのスイッチをオンに戻すことはできません。

## <a id="who-the-computer-is-offered-to"></a>誰に提供するか

スイッチがオンの間、誰に提供するかは[Webコンソール](/ja/guides/web-console/)で決めます。パソコンのページを開き、［Sharing］のカードを探します。スイッチが2つあり、チームに入っている間は3つになります。

- **Your other computers。** 同じアカウントのほかのパソコンから、このパソコンへ処理を送れるようにします。オフにすると、このパソコンは目の前の人専用になり、Team shareとPublic shareも同時にオフになります。
- **Public share。** 空きがある間、ほかのWairedユーザー（パブリックユーザー）がこのパソコンで処理を実行できるようにします。オンにしないかぎりオフです。先に[パブリック共有](/ja/public-share/)を読んでください。

チームに入っている間は、カードに3つ目のスイッチ［Team share］が表示され、このパソコンをチームメイトに貸せます。オンにしないかぎりオフです。先に[チーム共有](/ja/team-share/)を読んでください。

スイッチは連動しています。［Your other computers］をオフにすると、Public shareもオフになります。自分のマシンにも貸していないパソコンを他人に貸すことはないからです。Public shareをオンにすると、［Your other computers］もオンになります。Team shareも同じように連動します。

## <a id="how-much-work-it-takes-at-once"></a>同時に受ける処理の量

Webコンソールのパソコンのページでは、処理能力も設定します。

| 設定 | 動作 |
|---|---|
| **Requests at once** | このパソコンが同時に応答するリクエストの件数です。増やすほど並行して処理できますが、1件ごとにKVキャッシュ用のVRAMを確保するため、1件あたりの応答は遅くなります。`0`は自動です。コンソールには、いま適用されている値が欄の隣に、VRAMに収まる推奨最大値が注記に表示され、それを超える値にする前に確認されます。 |
| **Public share limit** | パブリックユーザーが同時に何件までこのパソコンを使えるかです。`0`は自動で、自分用に1件を残し、パブリックユーザーは最大2件です。このパソコンが同時に処理できる件数まで上げられます。 |
| **Main conversation**と**Sub-agents**（［Sharing］のカードの［Which requests］） | 共有しているすべての相手からのClaude CodeとOpenCodeのリクエストのうち、どの種類をこのパソコンが受けるかです。このパソコン自身のClaude CodeとOpenCodeには影響しません。［Main conversation］をオフにすると、遅いパソコンをサブエージェントの作業専用にできます。 |
| **Routing priority** | 複数のパソコンが答えられるとき、どれを先に選ぶかです。［High］が最初に選ばれ、［Low］は上位のパソコンが答えられない場合にだけ使われ、既定は［Middle］です。 |

<Aside type="note" title="自分の作業が優先されます">
	数値の設定にかかわらず、パソコンが混んでいるときは目の前の人の作業が優先されます。パブリックユーザーが長く邪魔することはなく、自分が使っている間はパブリックユーザーの新しい処理は待たされます。
</Aside>

## <a id="what-quitting-the-app-does"></a>アプリを終了するとどうなるか

Wairedアイコンの［Quit］は、推論エンジンを止め、アプリが閉じている間はすべての共有を止めます。誰もキーボードの前にいない間、このパソコンに処理は送られません。アプリを再び起動すると、すべて元の状態に戻ります。終了によって共有の設定そのものが変わることはありません。パソコンからのログアウトやシャットダウンも同じです。
