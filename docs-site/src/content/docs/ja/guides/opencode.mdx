## 接続する

```sh
waired link opencode
```

設定はこれだけです。`~/.config/opencode/plugin/waired.js` にプラグインが入り、
OpenCode の接続先が自分のモデルになります。あとは普段どおり OpenCode を起動してください。

<Aside type="tip" title="コーディングツールを複数入れている場合">
	`waired link` を名前なしで実行すると、見つかったツールをすべて設定します。
</Aside>

## 確認・削除

`waired doctor` が経路全体（接続、一時停止の有無、モデルの読み込み状況）を点検し、
**f** キーで直せるものは修復します。

連携を外すには:

```sh
waired unlink opencode
```

`waired link` が追加したものだけを取り消します。
