Wairedは、ホームフォルダに置く小さなプラグインを通じて、OpenCodeを自分のパソコンの
モデルに接続します。コーディングツールの質問にyesと答えていれば、セットアップが
インストールしています。このページでは、自分でインストールする方法、変更される
内容、削除の方法を説明します。

## <a id="connect-opencode"></a>OpenCodeを接続する

```sh
waired link opencode
```

セットアップはこれだけです。そのあといつもどおりOpenCodeを起動し、Wairedのモデルを
選択します。

<Expected>
	```
	opencode:    configured

	OpenCode integration:
	  - Plugin written to ~/.config/opencode/plugin/waired.js
	    (registers the 'waired' provider). Restart opencode to pick it up.
	```
	OpenCodeのモデル選択に、1つの項目を持つ**Waired**プロバイダーが追加されます。

	| モデル | 使うもの |
	|---|---|
	| `waired/default`（表示は**Waired Default**） | このパソコンでWairedが動かしているモデル |
</Expected>

APIキーも環境変数も使いません。WairedはOpenCodeを自分のパソコンのモデルに直接
接続します。

<Aside type="note" title="自分の既定のモデルは変わりません">
	連携は、選べるモデルの一覧にWairedのモデルを加えるだけです。OpenCodeが最初に
	使うモデルは、自分で設定したままです。使いたいときに`/models`か選択画面で
	Wairedのモデルに切り替えます。
</Aside>

<Aside type="tip" title="コーディングツールが複数ある場合">
	名前を付けずに`waired link`を実行すると、見つかったツールをすべて設定します。
	Claude Code、OpenCode、OpenClawが対象です。
</Aside>

## <a id="what-it-changed"></a>変更される内容

自分のホームフォルダの中の3つのファイルです。

| パス | 内容 |
|---|---|
| `~/.config/opencode/plugin/waired.js` | `waired`プロバイダーを登録する小さなプラグイン |
| `~/.config/opencode/commands/waired-status.md` | OpenCodeの中で使う`/waired-status`コマンド |
| `~/.config/opencode/commands/waired-doctor.md` | OpenCodeの中で使う`/waired-doctor`コマンド |

`opencode.json`は書き込まれず、ホームフォルダの外には触れません。

## <a id="check-it-or-remove-it"></a>確認と削除

[`waired doctor`](/ja/getting-started/doctor/)は、接続、ルーティングの一時停止、
モデルの読み込みまで、経路全体を検査します。`f`キーを押すと、直せるものを修復
します。OpenCodeの中では、`/waired-status`と`/waired-doctor`が同じ検査を行い、
結果をまとめて表示します。

連携を削除するには次のように実行します。

```sh
waired unlink opencode
```

`waired link`が追加したものだけを元に戻します。`~/.config/opencode/commands/`に
自分で置いたファイルと、OpenCodeがそこに書いたものは残ります。

連携の状態の確認と再適用は、Wairedアプリからもできます。**Wairedアイコン**を
選択し、［Settings］の［OpenCode］の項目を選択します。
