Wairedは、ホームフォルダに置く小さなプラグインを通じて、OpenClawを自分のパソコンのモデルに接続します。コーディングツールの質問にyesと答えていれば、セットアップがインストールしています。このページでは、自分でインストールする方法、変更される内容、削除の方法を説明します。

## <a id="connect-openclaw"></a>OpenClawを接続する

```sh
waired link openclaw
```

セットアップはこれだけです。そのあといつもどおりOpenClawを起動し、Wairedのモデルを選択します。

<Expected>
	OpenClawのモデル選択に、Wairedの項目が表示されます。

	| モデル | ターンが動く場所 |
	|---|---|
	| `waired/default` | 自分のコンピュータのどれか。200kのコンテキストウィンドウを持つコンピュータをWairedが選びます |
	| `waired/local` | このコンピュータ。200kのコンテキストウィンドウを持つ場合に限ります |
	| `waired/peer` | 200kのコンテキストウィンドウを持つ自分の別のコンピュータ。このコンピュータでは動きません |
	| `waired/peer-<名前>` | 名前で指定したコンピュータ。200kのコンテキストウィンドウを持つ場合に限ります |
	| `waired/public` | 200kのコンテキストウィンドウを持つ他の人のコンピュータ |
	| `waired/default[1m]`などの`[1m]`付きの項目 | 上と同じで、1Mのコンテキストウィンドウを持つコンピュータ。その項目に答えられるコンピュータが1Mを宣言している間だけ書き込まれます |
</Expected>

APIキーも環境変数も使いません。WairedはOpenClawを自分のパソコンのモデルに直接接続します。

項目が指しているのはモデルではなく**パソコン**です。答えたパソコンが、そのパソコンの持っているモデルで動かします。`waired/local`は、このパソコンにエンジンがあってローカル推論がオンのときだけ出ます。`waired/public`は、Public Shareをオンにしたときだけ出ます。`waired/peer-<名前>`は、連携したときに推論を提供していて、200,704トークン以上のコンテキストウィンドウを持っていた自分のコンピュータ1台につき1つ出ます。

項目が指しているパソコンが答えられないときは、黙って別の場所で動かさずに、理由を言って失敗します。どの項目も、`waired/local`と`waired/peer-<名前>`を含めて、200,704トークンのコンテキストウィンドウを持つコンピュータだけを使います。`[1m]`付きの項目は、1,048,576トークンを持つコンピュータだけを使います。どのコンピュータも満たさない場合、ターンは失敗し、必要だったコンテキストウィンドウを表示します。この一覧はClaude Codeの`/model`に出るものと同じです。各行の意味は[Claude Codeのターンはどこで実行されるか](/ja/guides/claude-code/how-turns-are-routed/)を参照してください。

プラグインは、どのコンピュータでもよい項目を`waired/default`として表示します。この名前で書いた設定はそのまま使えます。送信するときは、Claude Codeが送るのと同じidである`waired`として送ります。`waired/default[1m]`は`waired[1m]`として送ります。上の200kと1Mの条件を運ぶのはこれらのidです。

<Aside type="note" title="パソコンが増えたら`waired link openclaw`をもう一度実行します">
	OpenClawはモデルの一覧を`openclaw.json`から読みます。このファイルを書くのは連携のときです。別のパソコンの電源を入れたあと、もう一度`waired link openclaw`を実行すると、そのパソコンの項目が出ます。[`waired doctor`](/ja/getting-started/doctor/)で`f`を押すか、Wairedアプリの**Reconfigure**でも同じことができます。
</Aside>

<Aside type="note" title="自分の既定のモデルは変わりません">
	連携は、選べるモデルの一覧にWairedのモデルを加えるだけです。OpenClawが最初に使うモデルは、自分で設定したままです。使いたいときにWairedのモデルに切り替えます。
</Aside>

<Aside type="tip" title="コーディングツールが複数ある場合">
	名前を付けずに`waired link`を実行すると、見つかったツールをすべて設定します。Claude Code、OpenCode、OpenClawが対象です。
</Aside>

## <a id="what-it-changed"></a>変更される内容

自分のホームフォルダの中の2つです。

| パス | 内容 |
|---|---|
| `~/.openclaw/plugins/waired/` | 自分のモデルへの接続方法を知っている小さなプラグイン |
| `~/.openclaw/openclaw.json` | そのプラグインを有効にする2つの設定と、一覧に加えた上のモデル |

このファイルのほかの部分は変更されず、ホームフォルダの外には触れません。

`openclaw.json`がすでにあった場合、Wairedは最初の変更の前にそれを`~/.openclaw/openclaw.json.waired-bak-<timestamp>`にコピーします。書き戻すとキーの順序と書式が失われるので、自分が書いたままのファイルの記録はこのコピーだけです。変更が不要なときに`waired link openclaw`をもう一度実行しても、ファイル、そのタイムスタンプ、このコピーはそのままです。

## <a id="how-much-context-openclaw-is-told-about"></a>OpenClawに伝えるコンテキストの長さ

プラグインは、Wairedの項目ごとにコンテキストウィンドウを記録します。これにより、OpenClawは項目が示すウィンドウに達する前に会話を要約し、それより早くは要約しません。値は項目の名前だけで決まります。`[1m]`付きの項目は1048576トークン、それ以外の項目は`waired/local`と`waired/peer-<名前>`を含めて200704を示します。これは、どのコンピュータが答えても、Wairedが項目に求めるコンテキストウィンドウです。

項目は連携のときに書き込まれます。初回のセットアップ中はこのコンピュータがまだ推論を提供していないことが多く、その場合プラグインは`waired/default`だけで始まります。この項目も最初から200704を示します。`waired init`、`waired link all`、`waired doctor --fix`は、項目の一覧が変わったとき、またはプラグインを書いたのが古い版のWairedであるときにプラグインを更新し、そのことを表示します。

```
Updated OpenClaw's list of Waired models and their context windows.
```

プラグインが古くなっていると、`waired doctor`が次のいずれかの行で警告します。

```
! openclaw context window   the plugin was written by an older version of Waired
! openclaw context window   the plugin's list of Waired models is out of date
```

`f`キーを押すと最新の内容に更新されます。

## <a id="check-it-or-remove-it"></a>確認と削除

[`waired doctor`](/ja/getting-started/doctor/)は、接続、ルーティングの一時停止、モデルの読み込みまで、経路全体を検査します。`f`キーを押すと、直せるものを修復します。

連携を削除するには次のように実行します。

```sh
waired unlink openclaw
```

`waired link`が追加したものだけを元に戻します。元の`openclaw.json`のコピーはそのまま残り、`waired unlink`がそのパスを表示します。

連携の状態の確認と再適用は、Wairedアプリからもできます。**Wairedアイコン**を選択し、［Settings］の［OpenClaw］の項目を選択します。
