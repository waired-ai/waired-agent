「しばらく止めたい」には5つの意味があり、それぞれ結果が違います。まず自分に合う行を探してください。

| したいこと | 操作 |
|---|---|
| コーディングツールにしばらくクラウドを使わせたい | [ルーティングを一時停止する](#pause-routing) |
| このパソコンに答えるのをやめさせたい。ただしすぐ再開できる状態で | [ローカル推論を一時停止する](#pause-local-inference) |
| メモリをほかの用途に使いたい | [推論エンジンを止める](#stop-the-engine) |
| ほかの人やパソコンにこのパソコンのモデルを使わせたくない | [共有をやめる](#stop-sharing) |
| このパソコンをしばらくネットワークから外したい | [切断する](#disconnect) |
| このパソコンからWairedを削除したい | [Wairedをアンインストールする](/ja/getting-started/uninstall/) |

## <a id="pause-routing"></a>ルーティングを一時停止する

ツールは、Wairedがインストールされていないときと同じように、直接クラウドと通信するようになります。何もアンインストールされず、何も失われません。

```sh
waired pause
```

```sh
waired resume
```

この設定は再起動後も保持されます。一時停止したパソコンは、翌日も一時停止のままです。

<Expected title="反映を確認する">
```sh
waired doctor
```
**waired phase**の行が`active — overlay routing in effect`ではなく`paused`になります。
</Expected>

<Aside type="note" title="一時停止はすべてに効きます">
	一時停止中は、自分のモデルも答えません。`waired infer`や、ローカルゲートウェイに向けたチャットアプリには「not available」の応答が返ります。自分のモデルは使い続け、ほかのパソコンからの利用だけを止めるには、[共有をやめる](#stop-sharing)を参照してください。
</Aside>

## <a id="pause-local-inference"></a>ローカル推論を一時停止する

このパソコンは答えなくなりますが、モデルはメモリに載ったままなので、再開は一瞬です。このパソコンからのリクエストは、自分のほかのパソコンに送られます。どれも答えられない場合、リクエストは失敗してそのことを表示します。Wairedがクラウドに送ることはありません。

**Wairedアイコン**を選択し、［Inference］の［Pause local inference］を選択します。同じ項目が［Resume local inference］に変わります。

このスイッチはアプリだけにあります。インストール時の同じ設定は`waired init --inference-enabled=false`です。

<Aside type="caution" title="メモリは戻りません">
	一時停止は入口を閉じるだけで、停止ではありません。推論エンジンは動いたままで、モデルは数GBを保持し続けます。メモリを空けるには、[推論エンジンを止める](#stop-the-engine)を参照してください。
</Aside>

## <a id="stop-the-engine"></a>推論エンジンを止める

モデルが保持しているメモリ（通常は数GB）をすぐに解放します。設定は変わらず、推論エンジンを再び始めるとモデルが読み込み直されます。

<Tabs syncKey="mode">
	<TabItem label="Wairedアプリで">
		**Wairedアイコン**を選択し、［Inference］の［Stop inference engine］を選択します。同じ項目が［Start inference engine］に変わります。
	</TabItem>
	<TabItem label="ターミナルで">
		```sh
		waired inference engine stop
		waired inference engine start
		waired inference engine status
		```
	</TabItem>
</Tabs>

推論エンジンが止まっている間、このパソコンからのリクエストは、自分のほかのパソコンがあればそこに送られ、なければ再び始めるまで失敗します。

<Aside type="note" title="降ろすだけならパソコンは答え続けます">
	`waired inference unload`、またはアプリの［Unload model (free memory)］もモデルのメモリを解放しますが、推論エンジンは動いたままです。このパソコンは答え続け、次のリクエストでモデルを読み込み直します。しばらくメモリが必要なだけで、パソコンを外したいわけではないときに使います。
</Aside>

## <a id="stop-sharing"></a>共有をやめる

自分の利用はそのまま続きます。自分のほかのパソコンと公開のゲストは、このパソコンのモデルを使えなくなり、実行中の処理は打ち切られます。

<Tabs syncKey="mode">
	<TabItem label="Wairedアプリで">
		**Wairedアイコン**を選択し、［Inference］の［Stop sharing this computer］を選択します。
	</TabItem>
	<TabItem label="ターミナルで">
		```sh
		waired share off
		waired share on
		waired share status
		```
	</TabItem>
</Tabs>

自分のモデルは使い続けたいが、邪魔されたくないワークステーションに適した設定です。共有がオンのときに誰に提供されるかは、[自分の別のパソコンと共有する](/ja/guides/sharing/)を参照してください。

<Aside type="note" title="アプリを終了すると共有は自動で止まります">
	Wairedアイコンの［Quit］は、推論エンジンを止め、アプリが閉じている間はすべての共有を止めます。アプリを再び起動すると、すべて元の状態に戻ります。終了によって共有の設定そのものが変わることはありません。
</Aside>

## <a id="disconnect"></a>切断する

サインアウトせずに、このパソコンをプライベートネットワークから外します。自分のほかのパソコンからこのパソコンは見えなくなり、このパソコンからも見えなくなります。

**Wairedアイコン**を選択し、［Disconnect］を選択します。同じ項目が［Connect］に変わります。

<Aside type="caution" title="Sign out…とは違います">
	［Sign out…］はこのパソコンの識別情報を削除し、サインインし直すと新しいデバイスとして追加されます。［Disconnect］は行きも戻りもワンクリックで、恒久的な変更はありません。
</Aside>

## <a id="which-one-is-on"></a>いまどれが効いているか

```sh
waired status --observability
```

出力には、`active`か`paused`かのフェーズ、推論エンジンにモデルが載っているか、このパソコンがモデルをほかのパソコンに提供しているかが表示されます。

<Aside type="tip" title="混同されやすい3つのスイッチ">
	`waired pause`は、ルーティングもローカル推論も含めてこのパソコンのすべてを止めます。`waired inference off`は、このパソコンでモデルを動かすかどうかを決め、オフでもほかのパソコンのモデルは使います。`waired share off`は、ほかのパソコンとゲストがこのパソコンのモデルを使うことだけを止め、`waired infer`はここで動き続けます。
</Aside>
