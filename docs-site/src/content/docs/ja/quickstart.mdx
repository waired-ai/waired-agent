このページでは、何もインストールされていない状態から、自分のパソコンのモデルがClaude Codeに応答するまでの手順を説明します。コマンド1つでWairedをインストールし、サインインを始めます。残りの作業はブラウザで進めます。

## 始める前に

- モデルを動かすパソコン。手持ちでいちばん性能の高いパソコンを選びます。GPUを搭載したデスクトップか、AppleシリコンのMacが適しています。ノートパソコンからは、あとでどこからでもそのパソコンのモデルを使えます。パソコンが1台だけなら、その1台で動かして使います。
- Googleアカウント。
- そのパソコンの管理者権限。推論エンジンはシステム全体にインストールされます。

<Aside type="note" title="GPUは任意です">
	GPUがあると応答は速くなります。GPUのない最近のプロセッサでも、小さいモデルなら実用的な速度で動きます。
</Aside>

## 1. Wairedをインストールする

ターミナルを開き、自分のOSの行を貼り付けてEnterキーを押します。

<Tabs syncKey="os">
	<TabItem label="Windows">
		**PowerShellを管理者として**開きます。スタートボタンを右クリックし、［ターミナル（管理者）］を選択して、［はい］を選択します。

		```powershell
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/install.ps1 | iex
		```

		`iwr`がインストールスクリプトをダウンロードし、`iex`がそれを実行します。
	</TabItem>
	<TabItem label="macOS">
		**ターミナル**を開きます。⌘＋スペースを押し、`ターミナル`と入力してEnterキーを押します。

		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
		```

		`curl`がインストールスクリプトをダウンロードし、`sh`がそれを実行します。macOSのパスワードを求められます。入力中は画面に何も表示されませんが、正常な動作です。
	</TabItem>
	<TabItem label="Linux">
		ターミナルを開きます。

		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
		```

		`curl`がインストールスクリプトをダウンロードし、`sh`がそれを実行します。パスワードを求められます。入力中は画面に何も表示されませんが、正常な動作です。
	</TabItem>
</Tabs>

インストーラは、これから行う内容を一覧で表示し、`Proceed with the install? [Y/n] (Enter = Yes)`と確認します。Enterキーを押します。

このコマンドは、Wairedをインストールしてバックグラウンドで起動し、続けて同じウィンドウでサインインを始めます。ウィンドウは閉じないでください。

<Aside type="tip" title="実行する前にスクリプトを読む">
	スクリプトをダウンロードして内容を確認してから実行する手順は、OS別のページにあります：[Windows](/ja/getting-started/install/windows/#read-the-script-before-running-it)、[macOS](/ja/getting-started/install/macos/)、[Linux](/ja/getting-started/install/linux/)。
</Aside>

## 2. Googleでサインインする

インストールが終わると、同じウィンドウにサインイン用のリンクが表示されます。

<Expected title="ターミナルの表示">
```
To sign in, open this link:
  https://app.waired.ai/login/…

Control Plane: https://app.waired.ai

🌐 Press Enter to open the link in your browser, or open it yourself...
```
</Expected>

Enterキーを押します。ブラウザが開くので、Googleアカウントを選択します。表示されたリンクを自分で開いても構いません。このパソコンでも別のパソコンでも、どのブラウザでも使えます。どちらの場合も、ターミナルはサインインの完了を自動で検知します。

<Aside type="note" title="画面のないパソコンの場合">
	開くブラウザがないため、ターミナルはリンクを表示したうえで*「Nothing to press here. Sign-in continues on its own once you open the link.」*（ここで押すキーはありません）と伝えます。スマートフォンか別のパソコンでリンクを開いてください。ターミナルはそのまま先へ進みます。
</Aside>

サインインすると、ターミナルに次のように表示されます。

<Expected>
```
✅ Signed in as you@example.com
Waired is running in the background.

Setup is continuing in your browser...
   Keep this terminal window open until setup finishes. It does the parts the
   browser can't.
   (press Enter to continue in the terminal instead)
```
</Expected>

<Aside type="caution" title="このターミナルは閉じないでください">
	推論エンジンのインストールには管理者権限が必要で、ウェブページからは取得できません。実際の作業はターミナルが行い、ブラウザのページは進捗を表示します。ターミナルを閉じると、ブラウザのページに*「… のセットアップコマンドが完了前に終了しました。進捗は保存されています。」*と表示されます。`waired init`を実行すると、止まったところから再開します。

	ターミナル側の作業が終わると、*「nothing more is needed from this terminal」*（このターミナルで必要な作業はもうありません）と表示されます。それ以降は閉じて構いません。
</Aside>

## 3. ブラウザでセットアップを終える

開いたブラウザのタブに切り替えます。このパソコンのセットアップページが表示されています。

<Steps>

1. **推論エンジンを選びます。** ［Ollama（標準）］が選択されていて、どのパソコンでも動きます。［次へ］を選択します。ページが推論エンジンをインストールし、このパソコンの速度を計測します。数分かかります。

2. **モデルを選びます。** 一覧は推奨モデルが先頭に並び、各モデルがこのパソコンのメモリに収まるかどうかが表示されます。特に理由がなければ先頭のモデルのままにします。［続行］を選択すると、ダウンロードが始まります。

3. **各ステップの完了を待ちます。**

   <Screenshot
   	src="setup-wizard-progress-ja.png"
   	alt="ブラウザに表示されたWairedのセットアップページ。推論エンジンと速度計測のステップは完了、モデルのダウンロードは容量と転送速度つきで進行中、ベンチマークは待機中。"
   	caption="このタブは閉じても構いません。ダウンロードはバックグラウンドで続きます。"
   />

   | ステップ | 何をしているか | 所要時間 |
   |---|---|---|
   | **推論エンジンをダウンロード**、**推論エンジンをインストール** | モデルを読み込んで動かすプログラムです。インストールに管理者権限が必要です。 | 数分 |
   | **このコンピュータの速度測定に使う小さいモデルをダウンロード**、**このコンピュータの速度を計測** | このパソコンの応答速度を1回だけ計測します。 | 1〜2分 |
   | **コーディングツールと連携** | Claude Codeと、選択したほかのツールの接続先をWairedに向けます。 | 数秒 |
   | **モデルをダウンロード** | モデルの重みです。数GBあります。ページに進捗と転送速度が表示されます。 | 5〜30分 |
   | **推論速度をベンチマーク** | 選んだモデルで短い計測を行います。このパソコンには遅すぎる場合、より軽いモデルが提案されます。 | 最大5分 |

4. **完了します。** すべてのステップが完了したら、［セットアップを完了］を選択して自分のパソコンの一覧を開くか、［デバイスページへ］を選択してこのパソコンのページを開きます。

</Steps>

<Expected>
	すべてのステップにチェックが付き、ページに**「セットアップが完了しました — my-desktop は単体で推論できます。」**と表示されます。my-desktopの部分には自分のパソコンの名前が入ります。
</Expected>

<Expected tone="bad">
	*「完了するには、my-desktop で `sudo waired init` を実行してください。」*

	作業をしていたターミナルがなくなっています。閉じてしまったか、管理者権限がなかったかのどちらかです。ターミナルを開いて、そのコマンドを実行してください。進捗は保存されていて、止まったところから再開します。
</Expected>

<details>
<summary>ターミナルでセットアップする</summary>

*「Setup is continuing in your browser...」*の表示でEnterキーを押します。ターミナルが引き継ぐ前に、確認が表示されます。

```
   Taking over means this terminal drives setup and the browser page stops.
   Any model download keeps running either way.
   Take over setup in this terminal? [y/N] (default: No)
```

`y`と答えます。もう一度Enterキーを押すとNoと答えたことになり、ブラウザ側が引き続きセットアップを進めます。

次に、Claude CodeをWaired経由にするかを聞かれるので、`Y`と答えます。モデルのダウンロードは、進捗バーつきで進みます。

```
Starting the inference engine...
Preparing to download qwen3.8-27b...
Downloading qwen3.8-27b: 41%  7.3 GB / 17.7 GB (44 MB/s)
```

完了すると次のように表示されます。

```
╭─ 🎉 Waired is ready — setup is complete ──────────────╮
│ Account   you@example.com                             │
│ Model     qwen3.8-27b — 58 tok/s                      │
│ Claude    routed through Waired                       │
│ Local inference is running on this computer.          │
│ Point your coding agent at Waired and start building. │
╰───────────────────────────────────────────────────────╯
```

画面のないサーバーでは、ターミナルが唯一の方法です。詳しくは[ターミナルでセットアップする](/ja/getting-started/set-up-in-the-terminal/)を参照してください。

</details>

<Tabs syncKey="mode">
	<TabItem label="Wairedアプリで">
		**Wairedアイコン**を選択します。macOSではメニューバー、WindowsとLinuxでは時計のとなりにあります。

		<Screenshot
			src="app-ready.png"
			alt="Wairedアプリのメニュー。Connectedの状態、サインイン中のアカウント、readyと動作中のモデル名を示すEngineの行。"

			width="26rem"
		/>

		<Expected>
			メニューの最上部に「Connected」、その下に自分のメールアドレス、［Inference］に動作中のモデル名が表示されます。
		</Expected>
	</TabItem>
	<TabItem label="ターミナルで">
		```sh
		waired infer "say hi"
		```

		<Expected>
			数秒であいさつが返ってきます。この応答は自分のパソコンが生成したものです。クラウドの事業者には何も送られていません。
		</Expected>
	</TabItem>
</Tabs>

<Aside type="note" title="何も返ってこない場合">
	[`waired doctor`](/ja/getting-started/doctor/)を実行してください。セットアップの各項目を検査して✓、⚠、✗で表示し、`f`キーを押すと直せるものを修復します。初回のトラブルはたいていこれで解決します。
</Aside>

## 5. Claude Codeから使う

任意のプロジェクトでClaude Codeを開きます。`/model`と入力し、*Any of your computers*と説明のある［Waired］の行を選択します。そのあと何か質問します。フッターに、答えたモデルの名前が表示されます。

<Screenshot
	src="claude-code-statusline.png"
	alt="Claude Codeのフッターに表示されたWairedのステータス行。直前のリクエストに答えたローカルモデルの名前。"
/>

<Expected>
```
⚡ waired: on Waired (qwen3.8-27b)
```
自分のパソコンが、そのモデルで答えました。
</Expected>

モデルを選んでいないセッションは、Claude Codeの既定であるAnthropicのモデルで始まり、フッターには`→ waired: Anthropic`と表示されます。Wairedがこの既定を変えることはありません。`/model`はどちらの向きにも切り替えられます。自分のパソコンを使うなら［Waired］の行、クラウドを使うならAnthropicのモデルを選択します。変更は次のメッセージから反映されます。
