Wairedの削除は約10秒で終わり、バックグラウンドに何も残りません。先に、設定とダウンロード済みのモデルを残すかどうかを決めます。

## <a id="which-removal-you-want"></a>どちらの削除をするか

|  | **アプリだけ削除する** | **すべて削除する** |
|---|---|---|
| Wairedアプリとバックグラウンドサービス | 終了して削除 | 終了して削除 |
| Claude Codeとコーディングツールの設定 | 削除 | 削除 |
| デバイス一覧のこのパソコン | 削除 | 削除 |
| 設定とこのデバイスの識別情報 | **残す** | 削除 |
| ダウンロード済みのモデル（数GB） | **残す** | 削除 |
| あとで再インストールしたとき | 新規にサインイン | 新規にサインイン |

ディスクの空きが足りない場合や、パソコンを人に渡す場合を除き、**アプリだけ削除する**を選びます。

## <a id="remove-the-app"></a>アプリだけ削除する

<Tabs syncKey="os">
	<TabItem label="Windows">
		セットアッププログラムでインストールした場合は、Windowsの通常の方法で削除します。［設定］>［アプリ］>［インストールされているアプリ］>［Waired］>［アンインストール］を選択します。

		<details>
		<summary>コマンドで削除する</summary>

		```powershell
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.ps1 | iex
		```

		セットアッププログラムでインストールした場合を含め、インストール方法を問わず使えます。

		</details>
	</TabItem>
	<TabItem label="macOS">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.sh | sh
		```
	</TabItem>
	<TabItem label="Linux">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.sh | sh
		```
	</TabItem>
</Tabs>

アンインストーラは、これから削除するものを一覧で表示し、`Proceed with the uninstall? [y/N]`と確認します。Enterキーを押すと中止されます。進めるには`y`と入力します。

Wairedアプリが開いている場合は、アンインストーラが先にアプリを終了し、アプリ名とプロセスIDを表示します。

```
[waired] Stopping the Waired app (waired-tray, PID 4321)
```

最後に次のように表示されます。

```
[waired] Waired removed. Local config and state were kept; re-run with --clean to wipe them.
```

<Aside type="tip" title="何が行われるかを先に確認する">
	`--dry-run`（Windowsでは`-DryRun`）を付けると、アンインストーラは何も変えずにすべての手順を表示します。
</Aside>

## <a id="remove-everything-including-models"></a>モデルも含めてすべて削除する

設定、このデバイスの識別情報、Wairedが持つ推論エンジンのコピーとダウンロードしたすべてのモデルも削除します。元に戻すことはできません。

<Tabs syncKey="os">
	<TabItem label="Windows">
		```powershell
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.ps1 -OutFile $env:TEMP\uninstall.ps1
		& $env:TEMP\uninstall.ps1 -Clean
		```

		1行の形では`-Clean`オプションを渡せないため、2行に分けます。
	</TabItem>
	<TabItem label="macOS">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.sh | sh -s -- --clean
		```
	</TabItem>
	<TabItem label="Linux">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.sh | sh -s -- --clean
		```
	</TabItem>
</Tabs>

<Aside type="note" title="自分でインストールしたOllamaの扱い">
	Wairedは推論エンジンの独自のコピーを自分のフォルダに置くので、Wairedを削除するとそのコピーも削除されます。自分で別途インストールしたOllamaの扱いはOSで異なります。

	- **macOS**: アプリケーションフォルダの**Ollama**には触れません。削除したい場合はゴミ箱に入れ、ダウンロードしたモデルは`~/.ollama`を削除します。
	- **Windows**: 「すべて削除する」は文字どおりです。`Program Files`やユーザーフォルダのOllamaも、そのモデルごと削除されます。残したい場合は、上の通常のアンインストールを使います。
	- **Linux**: Windowsと同じです。システム全体にインストールされたOllamaは削除されます。
</Aside>

## <a id="after-you-uninstall"></a>削除したあと

- **ほかのパソコンには影響しません。** ネットワークに残り、そのまま動きます。このパソコンがモデルを動かしていた場合、別のモデルをセットアップするまで、ほかのパソコンには使えるモデルがありません。
- **デバイスはアカウントから消えます。** 削除したときにパソコンがオフラインだった場合は、一覧に残ることがあります。[app.waired.ai](https://app.waired.ai)のデバイス一覧から削除してください。
- **料金は発生しません。** Wairedはメッセージごとの課金をしていません。

## <a id="claude-code-says-connection-refused-after-waired-is-gone"></a>Wairedを消したあとにClaude CodeがConnection refusedと言う

Wairedを別の方法で消した場合、たとえば手で削除した、`apt remove waired`で削除した、古いアンインストーラで削除した場合は、Claude Codeのコンピュータ全体の設定がWairedを指したまま残ることがあります。すると、すべてのリクエストが次のエラーで失敗します。

```
API Error: Connection refused — a firewall or proxy may be blocking it (ConnectionRefused)
```

[アプリだけ削除する](#remove-the-app)のアンインストールコマンドをもう一度実行します。`waired`プログラムが無くても、残っているClaude Codeの設定を見つけて削除し、最後に次のように表示します。

```
[waired] Waired wasn't installed, but Claude Code still had Waired's settings. They were removed. Restart Claude Code for the change to take effect.
```

そのあと、Claude Codeを再起動します。

アンインストーラは、ステータス行や`/model`のWairedの行など、自分のClaude Codeの設定も片付けますが、対象は実行したユーザーの分だけです。GNOME SoftwareなどのソフトウェアセンターやrootのシェルからWairedを消した場合は、rootではなく、Claude Codeを使っているユーザー自身でアンインストールコマンドを実行してください。Wairedはほかのユーザーのホームフォルダを見に行きません。

Linuxでは、アンインストーラが設定ファイルを編集するのに`python3`が必要です。無い場合はファイルに触れず、次の警告を表示します。

```
[waired] Warning: /etc/claude-code/managed-settings.json may still point Claude Code at Waired, and there's no python3 on this computer to check it. Remove Waired's settings from it by hand.
```

手で直すには、管理者としてファイルを開き、2つを削除します。値が`http://127.0.0.1:`で始まる`ANTHROPIC_BASE_URL`と、コマンドに`waired claude`を含むフックです。ファイルのほかの内容はそのまま残し、Claude Codeを再起動します。

| | managed settingsのファイル |
|---|---|
| Windows | `C:\Program Files\ClaudeCode\managed-settings.json` |
| macOS | `/Library/Application Support/ClaudeCode/managed-settings.json` |
| Linux | `/etc/claude-code/managed-settings.json` |

## <a id="start-over-on-the-same-computer"></a>同じパソコンで最初からやり直す

初期化と再インストールを一度に行うには、cleanオプションを付けてインストーラを実行します。上の「すべて削除する」を行ったうえで、新規にインストールします。

<Tabs syncKey="os">
	<TabItem label="Windows">
		```powershell
		$env:WAIRED_CLEAN = '1'
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/install.ps1 | iex
		```

		確認画面は2回表示されます。初期化に1回、インストールに1回です。
	</TabItem>
	<TabItem label="macOS">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh -s -- --clean
		```
	</TabItem>
	<TabItem label="Linux">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh -s -- --clean
		```
	</TabItem>
</Tabs>

インストーラは、初期化の前に確認します。初期化でこのデバイスの識別情報が削除されるため、そのあとのサインインでは新しいデバイスとして追加されます。
