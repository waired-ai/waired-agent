Wairedは、3つのOSのどれでもコマンド1つでインストールできます。ターミナルに1行貼り付けると、インストーラがこれから行う内容を表示するので、確認して進めます。Windowsでは、ダブルクリックで実行するセットアッププログラムも使えます。

はじめてセットアップする場合は、代わりに[クイックスタート](/ja/quickstart/)に従ってください。インストールとセットアップを一度に進められます。

## 動作環境

| 役割 | 対応環境 |
|---|---|
| **モデルを動かす** | Ubuntu 24.04以降、Debian trixie以降、Windows 11、Windows Server 2025、macOS 13以降。MacではAppleシリコンを推奨します。 |
| **モデルを使う** | 上記のいずれか。GPUは不要です。 |

GPUがあると応答は大幅に速くなります。最近のプロセッサなら、小さいモデルは実用的な速度で動きます。入力する側のパソコンに特別な要件はありません。

各モデルに必要なメモリは[モデルカタログ](/ja/reference/model-catalog/)に載っています。インストール前に読む必要はありません。セットアップが、このパソコンに収まるモデルを選びます。

## インストーラがパソコンに置くもの

- **Waired本体。** このパソコンを接続し続けるバックグラウンドサービスと、`waired`コマンドです。サービスは、誰かがログインする前にパソコンの起動時に始まります。
- **Wairedアプリ。** 日常の操作に使うアイコンです。macOSではメニューバー、WindowsとLinuxでは時計のとなりに表示されます。

推論エンジンはインストールに含まれません。数GBのダウンロードになるため、このパソコンでモデルを動かすことを選んだ場合にだけ、セットアップの途中でインストールされます。

どのインストーラも、これから行う内容の一覧を表示し、何かを変更する前に`Proceed with the install? [Y/n] (Enter = Yes)`と確認します。

<Aside type="tip" title="ターミナルを使ったことがない場合">
	OS別のページは、ターミナルの開き方から説明しています。各コマンドには、何をするかを説明する文を添えています。この1つのコマンドのあとは、ブラウザとWairedアプリだけで操作できます。
</Aside>
