1台のパソコンでモデルが動いていれば、サインインしたほかのパソコンからも、自宅でも職場でもカフェのWi-Fiでも、そのモデルを使えます。同じGoogleアカウントでサインインすることが、同じプライベートネットワークに加わる条件です。ペアリングの操作も、アドレスの入力もありません。

## <a id="on-the-new-computer"></a>新しいパソコンでの手順

<Steps>

1. **Wairedをインストールします。** [Windowsにインストールする](/ja/getting-started/install/windows/)、[macOSにインストールする](/ja/getting-started/install/macos/)、[Linuxにインストールする](/ja/getting-started/install/linux/)を参照してください。

2. **1台目と同じGoogleアカウントでサインインします。** インストーラがサインインを始めます。

3. **このパソコンではモデルを動かさない設定にします。** このパソコンもモデルを動かせる性能がある場合を除きます。ブラウザでは［このコンピュータではローカル推論を動かさない］を選択します。ターミナルでは*Run models on this computer?*に`n`と答えます。モデルを使うだけのノートパソコンは何もダウンロードしません。最初にセットアップしたパソコンが代わりに答えます。

</Steps>

## <a id="check-that-it-reaches-the-first-computer"></a>1台目に届いているか確認する

```sh
waired status --observability
```

**Mesh**の行を読みます。

```
Mesh:     2 enrolled / 1 reachable / 1 ready
```

- **enrolled**は、ネットワークにあるパソコンの台数です。
- **reachable**は、このパソコンがいま通信できる台数です。
- **ready**は、そのうちモデルを読み込んで提供している台数です。

ノートパソコンで`1 reachable / 1 ready`と出れば、モデルを動かしているパソコンが起動していて利用できます。`0 reachable`と出る場合は、[別のパソコンがモデルに届かない](/ja/troubleshooting/other-computers/#my-other-computer-cannot-reach-the-model)を参照してください。

そのあと、何か質問してみます。

```sh
waired infer "say hi"
```

答えは、暗号化された接続を通って別のパソコンから返ってきます。

## <a id="which-computer-answers"></a>どのパソコンが答えるか

既定では、Wairedが自動で選びます。このパソコンにモデルがあればそれを使い、なければ自分のほかのパソコンに依頼します。常に特定のパソコンを使う、または優先するには、[どのパソコンが答えるかを選ぶ](/ja/guides/routing/)を参照してください。

<Aside type="note" title="ルーターの設定は不要です">
	パソコンどうしは、ネットワークが許せば直接接続し、ファイアウォールに阻まれる場合は暗号化されたリレーに切り替わります。どちらも自動です。ポート転送もVPNの設定も必要ありません。
</Aside>

## <a id="remove-a-computer-later"></a>あとからパソコンを外す

パソコンでWairedをアンインストールすると、一覧から外れます。もう操作できないパソコンを外すには、[app.waired.ai](https://app.waired.ai)のデバイス一覧を開き、そこで削除します。
