1行のインストーラは、64ビットのx86とARMで、Ubuntu 24.04以降とDebian trixie以降に
対応しています。Wairedのaptリポジトリを追加するので、更新はほかのシステム
パッケージと同じ方法で届きます。

## <a id="install"></a>インストール

<Steps>

1. ターミナルを開いて、次の行を実行します。

   ```sh
   curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
   ```

   `curl`がインストールスクリプトをダウンロードし、`sh`がそれを実行します。

2. 表示された一覧を確認し、`Proceed with the install? [Y/n] (Enter = Yes)`で
   Enterキーを押します。

3. 求められたらパスワードを入力します。入力中は画面に何も表示されませんが、正常な
   動作です。

</Steps>

インストーラは、続けて同じウィンドウでサインインを始めます。
[サインインする](/ja/getting-started/sign-in/)に進んでください。

<Aside type="tip" title="実行する前にスクリプトを読む">
	スクリプトをダウンロードし、内容を読んでから実行します。

	```sh
	curl -fsSLO https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh
	less install.sh    # press q to quit
	sh install.sh
	```
</Aside>

## <a id="other-distributions"></a>ほかのディストリビューション

インストーラが設定できるのはaptリポジトリだけなので、Fedora、Arch、Alpineなどには
まだ対応していません。[最新のリリース](https://github.com/waired-ai/waired-agent/releases/latest)から
プログラムを取得し、サービスを自分で登録すればWairedを動かせます。ただし、この
方法は自動化されておらず、更新も手動です。

## <a id="the-icon-on-gnome"></a>GNOMEでのアイコン

GNOMEは、拡張機能なしでは時計のとなりにアイコンを表示しません。そのため、Wairedの
アイコンにはAppIndicator拡張機能が必要です。セットアップは、パソコンにGNOMEが
あると拡張機能をインストールして有効にし、以後もログインのたびに確認します。
拡張機能が無効になっていれば、Wairedが再び有効にします。それでもアイコンが
表示されない場合は、`waired doctor --fix`を実行するか、
[Wairedのアイコンが表示されない](/ja/troubleshooting/#the-waired-icon-is-missing-linux)を
参照してください。KDE Plasmaでは何も必要ありません。デスクトップのないパソコンには
何もしません。

## <a id="skip-the-inference-engine"></a>推論エンジンを入れない

Wairedは、モデルを動かすパソコンにだけ、セットアップの途中で推論エンジンの
[Ollama](https://ollama.com)をインストールします。推論エンジンを入れたくない
場合は、次のように実行します。

```sh
curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh -s -- --skip-ollama
```

あとから追加するには、`sudo waired runtimes install ollama`を実行します。

## <a id="what-gets-installed"></a>インストールされるもの

| | |
|---|---|
| パッケージ | `waired`と`waired-tray`。Wairedのaptリポジトリから |
| バックグラウンドサービス | `waired-agent.service`（systemd）。起動時に開始 |
| 設定 | `/etc/waired` |
| 状態 | `/var/lib/waired` |
