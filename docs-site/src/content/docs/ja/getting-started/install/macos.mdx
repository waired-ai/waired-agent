macOS 13（Ventura）以降に対応します。この Mac でモデルを動かすなら
**Apple Silicon を強く推奨**します。ユニファイドメモリのおかげで、ノートパソコンでも
実用的なモデルを載せられます。

<Aside type="note" title="ドラッグして入れるアプリはまだありません">
	`.dmg` も Homebrew formula もまだなく、バイナリにはコード署名がありません
	（どちらも予定されています）。現時点では、ターミナルに 1 行貼り付ける形になります
	— それでも **Waired** はアプリケーションフォルダに入ります。ドラッグ元の
	ディスクイメージが無いだけです。
</Aside>

## インストール

<Steps>

1. **ターミナル**を開きます: ⌘ + スペース →「ターミナル」と入力 → Enter。

2. 次の行を貼り付けて Enter を押します。

	```sh
	curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
	```

	`curl` が Waired のインストールスクリプトをダウンロードし、`sh` が実行します。

3. 表示された内容を確認し、`Proceed? [Y/n]` で Enter を押します。

4. Mac のパスワードを入力します。

	**入力しても画面には何も表示されません。** ターミナルのパスワード入力はそういう
	仕様で、固まっているわけではありません。そのまま入力して Enter を押してください。

	パスワードが必要なのは、常駐サービスをマシン全体に登録し、誰もログインしていなくても
	起動時から動くようにするためです。

</Steps>

次は[サインインとセットアップ](/ja/getting-started/first-run/)です。

<Aside type="tip" title="スクリプトをそのままシェルに流すのが不安な場合">
	もっともです。先にダウンロードして読んでから実行できます。

	```sh
	curl -fsSLO https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh
	less install.sh    # q キーで終了
	sh install.sh
	```
</Aside>

## 推論エンジンを入れない

モデルを動かすプログラム（[Ollama](https://ollama.com)）は、セットアップ時に、
モデルを動かすパソコンにだけ導入されます。まったく入れたくない場合:

```sh
curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh -s -- --skip-ollama
```

あとから `sudo waired runtimes install ollama` で追加できます。

## インストールされるもの

| | |
|---|---|
| コマンド | `/usr/local/bin/waired`、`/usr/local/bin/waired-agent` |
| Waired アプリ | `/Applications/Waired.app` — メニューバーのアイコン |
| 常駐サービス | システムの `launchd` デーモン（起動時から動作） |
| 設定と状態 | `/Library/Application Support/waired` |
| 推論エンジンとモデル | `/Library/Application Support/waired` の中（モデルを動かすパソコンのみ） |

インストーラが Waired アプリを起動します。以後はサインインのたびに戻ってきます。
SSH 越しにインストールした場合は開く先の画面セッションがないので、そのときは
Launchpad から **Waired** を一度開いてください。それ以降は毎回のログインで起動します。

**推論エンジン**だけは例外で、アプリケーションフォルダにもう 1 つアプリを置くのではなく、
Waired が自分の設定と同じ場所に持ちます。ここに挙げた場所以外には何も触れません。
この Mac にすでに Ollama が入っている場合、Waired はそれに触れず、使いもしません。
