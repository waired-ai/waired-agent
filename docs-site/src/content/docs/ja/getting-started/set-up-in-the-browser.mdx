[サインイン](/ja/getting-started/sign-in/)のあと、ブラウザにこのパソコンのセットアップページが開きます。このページでは、そこで聞かれることと行われることを説明します。サインインを始めたターミナルはバックグラウンドで開いたままになり、管理者権限が必要なステップを実行します。

## <a id="1-choose-the-inference-engine"></a>1. 推論エンジンを選ぶ

ページは最初に、このパソコンでモデルをどう動かすかを聞きます。

- **Ollama（標準）。** *GPU の有無を問わず、どのコンピュータでも動作します。*ほとんどの人に適した選択肢で、既定で選択されています。
- **vLLM（高性能）。** *大幅に高速ですが、高性能なNVIDIA GPUを搭載したLinuxマシンが必要です。* ほかの環境ではグレー表示になります。
- **このコンピュータではローカル推論を動かさない。** 別のパソコンのモデルを使うだけのノートパソコンではこれを選びます。ネットワークには加わり、何もダウンロードしません。

［次へ］を選択します。ページには*「「次へ」で my-desktop に推論エンジンを導入し、ベンチマークを実行します。モデルの選択はその後です。」*と表示されます。my-desktopの部分には自分のパソコンの名前が入ります。推論エンジンの導入と速度の計測には数分かかります。その間にモデルを選べます。

## <a id="2-pick-a-model"></a>2. モデルを選ぶ

一覧には、このパソコンで動かせるモデルが推奨モデルを先頭に表示されます。各モデルには*重み 約 5.2 GB + KV キャッシュ 約 1.2 GB*のようにメモリの使用量が示されます。このパソコンに合わないモデルには、メモリに収まらない、応答が遅くなる、といった理由が表示されます。

同じ画面に、既定でオンのスイッチが2つあります。

- **コーディングツールと連携。** Claude Code、OpenCode、OpenClawの接続先をWairedに向けます。Claude Codeについては、このパソコンを使う全員に適用されるパソコン全体の変更です。
- **モデルのダウンロード後にベンチマークを実行する。** 数分かかります。このパソコンがモデルに追いつけるかをWairedが判断するための計測です。

［続行］を選択すると、ダウンロードが始まります。

<Aside type="note" title="推論エンジンがまだないパソコン">
	推論エンジンのインストールが終わるまで、［続行］は無効のままです。ページには*「my-desktop に推論エンジンを導入中。準備ができ次第、ベンチマークを実行します。先にモデルを選ぶことも、ベンチマークを待つこともできます。」*と表示されます。
</Aside>

## <a id="3-wait-for-the-steps"></a>3. ステップの完了を待つ

<Screenshot
	src="setup-wizard-progress-ja.png"
	alt="ブラウザに表示されたWairedのセットアップページ。推論エンジンと速度計測のステップは完了、モデルのダウンロードは容量と転送速度つきで進行中、ベンチマークは待機中。"
	caption="各ステップはパソコン自身が報告します。このタブを閉じても止まりません。"
/>

| ステップ | 何をしているか | 所要時間 |
|---|---|---|
| **推論エンジンをダウンロード** | モデルを動かすプログラムを取得します。Ollamaは約1.5GB、vLLMは約4GBです。 | 数分 |
| **推論エンジンをインストール** | 展開して登録します。管理者権限が必要なステップで、ターミナルを開いておく理由はここにあります。 | 1〜2分。vLLMは最大15分 |
| **このコンピュータの速度測定に使う小さいモデルをダウンロード**、**このコンピュータの速度を計測** | このパソコンの応答速度を1回だけ計測します。 | 1〜2分 |
| **コーディングツールと連携** | 選択したツールの接続先をWairedに向けます。これにも管理者権限が必要なのでターミナルが行い、長いダウンロードの前に済ませます。 | 数秒 |
| **モデルをダウンロード** | モデルの重みです。数GBあります。ページに進捗と転送速度が表示されます。 | 5〜30分 |
| **推論速度をベンチマーク** | 選んだモデルで短い計測を行います。 | 最大5分 |

することのないステップは省略されます。推論エンジンがすでにあるパソコンでは、すぐにモデルのダウンロードに進みます。

ページはいつ離れても構いません。*「このページを離れても、セットアップはバックグラウンドで続行されます。」*と表示されます。戻るには、[Webコンソール](/ja/guides/web-console/)でこのパソコンのページを開き、［セットアップを再開］を選択します。

<Aside type="caution" title="ターミナルを閉じないでください">
	セットアップの実行中、ページには「ターミナルを閉じないでください」というお知らせが表示されます。*「my-desktop のターミナルとインストールスクリプトを閉じないでください。セットアップが完了するまで、実行したままにしてください。」*インストールを行っているのはターミナルです。ページは進捗を表示するだけです。
</Aside>

## <a id="4-finish"></a>4. 完了する

<Expected>
	すべてのステップにチェックが付き、ページに**「セットアップが完了しました — my-desktop は単体で推論できます。」**と表示されます。Claude Codeと連携した場合は、*「このコンピュータの全ユーザーの Claude Code が、Waired 経由で接続されるようになりました。」*が続きます。
</Expected>

［セットアップを完了］を選択すると自分のパソコンの一覧が開き、［デバイスページへ］を選択するとこのパソコンのページが開きます。

ベンチマークで、選んだモデルにはこのパソコンが遅すぎると分かった場合は、ページにその旨が表示され、［別のモデルを選択］が提示されます。勝手に決められることはありません。遅いモデルでも動くので、そのままにしても構いません。

## <a id="if-the-page-shows-an-error"></a>ページにエラーが表示される場合

| ページの表示 | 対処 |
|---|---|
| *「my-desktop のセットアップコマンドが完了前に終了しました。進捗は保存されています。」* | ターミナルが閉じられました。ターミナルを開いて`waired init`（macOSとLinuxでは`sudo waired init`）を実行します。セットアップは止まったところから続きます。 |
| *「my-desktop でのセットアップの続行には管理者権限が必要です。」* | ターミナルが管理者権限なしで起動されています。管理者のターミナルを開いて、`waired init`をもう一度実行します。 |
| *「my-desktop のディスク空き容量が不足しています。」* | 空き容量を確保してから、`waired init`をもう一度実行します。 |
| *「my-desktop でダウンロードを完了できませんでした。インターネット接続を確認してください。」* | 接続を確認してから、`waired init`をもう一度実行します。ダウンロードは途中から再開します。 |
| *「my-desktop に推論エンジンはインストールされていますが、起動できません。」* | [セットアップの問題](/ja/troubleshooting/setup/#setup-says-the-inference-engine-failed-to-start)を参照してください。 |
| *「my-desktop の推論エンジンのバージョンが古いため、このモデルを利用できません。」* | `waired update`を実行してから、モデルを選び直します。 |

そのほかの場合は、そのパソコンで`waired doctor`を実行してください。準備ができていない部分が表示されます。

## <a id="what-the-terminal-does-meanwhile"></a>その間にターミナルが行うこと

ブラウザがセットアップを進めている間、ターミナルは何も聞きません。閉じないよう表示するだけです。選択したコーディングツールの接続は、ページにはない管理者権限が必要なため、ターミナルが行います。

```
Keep this terminal window open until setup finishes — it does the parts the
browser can't.
🔌 Setting up your coding tools (claude-code, openclaw, opencode)...
```

ターミナル側の作業が終わると、*「Setup is continuing in your browser — nothing more is needed from this terminal」*と表示されます。それ以降は閉じて構いません。モデルのダウンロードとベンチマークにターミナルは必要ありません。

<Aside type="note" title="ターミナルに引き継ぐ">
	*「Setup is continuing in your browser...」*の表示でEnterキーを押すと、セットアップをターミナルへ移すかを聞かれます。[ターミナルでセットアップする](/ja/getting-started/set-up-in-the-terminal/)を参照してください。
</Aside>
