Waired runs a model on one computer you already own and lets every other
device you sign in on use it. Your prompts travel between your own devices
over an encrypted link, and nothing is billed per message.

## What you get

- **No per-message bill.** The model runs on hardware you already paid for.
- **Your prompts stay yours.** They travel between your own devices over an
  encrypted link. Waired's servers introduce your devices to each other and
  never see what you send.
- **Your tools stay the same.** Claude Code, OpenCode, OpenClaw, and any
  OpenAI-compatible app keep working as before. Only the place the answer comes
  from changes.
- **It works away from home.** Your laptop reaches the model on your desktop
  from a café or an office. You do not set up a VPN or open ports.

## What Waired is not

- **Not a chat app.** Waired has no chat window of its own. It points the tools
  you already use at your own model.
- **Not a way to run the largest models.** What you can run depends on your
  hardware. A good desktop runs a capable coding model, and a thin laptop runs
  a small one. Waired tells you which models fit before you download one.
- **Not something that falls back to the cloud on its own.** When your own
  model cannot answer, the request fails and Waired says why. The cloud answers
  only when you pick a cloud model in your tool, and the footer shows which
  side answered.

## What it costs to run

Nothing per message. You need one computer that stays on while you use it, and
enough memory for the model. The [model catalog](/reference/model-catalog/)
lists the memory each model needs.

<Aside type="note" title="A GPU is optional">
	A GPU makes answers much faster, so if you have one, run the model on that
	computer. A recent processor without a GPU still runs a small model at a
	usable speed.
</Aside>

## How it works

Every computer you sign in on joins a private network of your own. When you
send a request, Waired picks the computer that should run it, this one or
another, and sends the request there over an encrypted connection. The cloud
is not part of that choice. It answers only when you pick a cloud model
yourself.

Your devices connect directly to each other whenever the network allows. When
a firewall prevents that, an encrypted [relay](/reference/glossary/#relay)
passes the sealed data along without being able to read it.
