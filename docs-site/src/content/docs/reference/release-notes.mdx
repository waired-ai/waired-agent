## The full list of changes

Every release, with what changed in it, is published on GitHub:

**[github.com/waired-ai/waired-agent/releases](https://github.com/waired-ai/waired-agent/releases)**

That page is the authority. Each entry names the version, the date, and what
was fixed or added, and carries the installers for every platform.

## Stable and edge

| Channel | What it is | Who it is for |
|---|---|---|
| **stable** | The numbered releases, in order. The default. While Waired is in pre-release, those are release candidates. | Everyone. |
| **edge** | Rebuilt from the latest source every time something is merged. | People who want a fix before it is released, and do not mind the occasional rough edge. |

To switch between them:

```sh
waired update --edge      # move to edge
waired update --stable    # move back
```

<Aside type="caution" title="Edge is not tested the way a release is">
	Every edge build passes automated checks, but a release additionally gets
	real-hardware install and inference testing on all three operating
	systems. On a computer you depend on, stay on stable.
</Aside>

## Keeping up to date

```sh
waired update --check     # is there a newer one?
waired update             # install it
```

The Waired app shows a notice near the top of its menu when an update is
available. See [Update Waired](/getting-started/update/).

<Aside type="note" title="If a page here describes something you do not have">
	Update first, then reread the page. If it still does not match after
	updating, that is a documentation bug. Please
	[open an issue](https://github.com/waired-ai/waired-agent/issues) with the
	page address and the output of `waired version`.
</Aside>
