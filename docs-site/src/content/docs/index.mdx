Type in Claude Code on any laptop and the answer comes from a computer you
own. No per-message bill, no subscription, and your prompts stay on your own
devices.

## Why people run it

<CardGrid>
	<IconLinkCard title="One command" icon="rocket" href="/quickstart/">
		Install with a single line, sign in with Google, and finish in the
		browser or the terminal. About ten minutes either way.
	</IconLinkCard>
	<IconLinkCard title="Free to run" icon="approve-check" href="/reference/model-catalog/">
		The model runs on hardware you already own. A recent processor is enough,
		and a GPU makes it fast. See what fits your computer.
	</IconLinkCard>
	<IconLinkCard title="Private by default" icon="padlock" href="/concepts/privacy/">
		Your devices talk directly over an end-to-end encrypted link. Waired's
		own servers never see your prompts or replies.
	</IconLinkCard>
	<IconLinkCard title="Your tools, unchanged" icon="puzzle" href="/guides/claude-code/">
		Claude Code, OpenCode, OpenClaw, and any OpenAI-compatible client keep
		working. What changes is where the answer comes from.
	</IconLinkCard>
</CardGrid>

## Install in one command

<Tabs syncKey="os">
	<TabItem label="Windows">
		From **Terminal (Administrator)**, which you open by right-clicking the
		Start button:

		```powershell
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/install.ps1 | iex
		```
	</TabItem>
	<TabItem label="macOS">
		From **Terminal**, which you open with ⌘ + Space and typing `Terminal`:

		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
		```
	</TabItem>
	<TabItem label="Linux">
		From a terminal, on Ubuntu 24.04 or later or Debian trixie or later:

		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
		```
	</TabItem>
</Tabs>

The installer shows what it will do and asks before changing anything. Then
you finish setup in the browser or in the terminal. The
[Quickstart](/quickstart/) covers both.
