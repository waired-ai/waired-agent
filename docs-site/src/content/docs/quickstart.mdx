This page takes you from nothing installed to Claude Code answering from a
model on your own computer. One command installs Waired and starts sign-in.
The rest happens in your browser.

## Before you start

- A computer to run the model on. Use the most powerful computer you own, such
  as a desktop with a GPU or a Mac with Apple Silicon. Your laptop can use that
  computer's model later from anywhere. If you own one computer, use it for
  both.
- A Google account.
- Administrator rights on that computer. The inference engine is installed
  system-wide.

<Aside type="note" title="A GPU is optional">
	A GPU makes answers faster. A recent processor without one still runs a small
	model at a usable speed.
</Aside>

## 1. Install Waired

Open a terminal, paste the line for your system, and press Enter.

<Tabs syncKey="os">
	<TabItem label="Windows">
		Open **PowerShell as Administrator**: right-click the Start button, select
		**Terminal (Administrator)**, then select **Yes**.

		```powershell
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/install.ps1 | iex
		```

		`iwr` downloads the install script and `iex` runs it.
	</TabItem>
	<TabItem label="macOS">
		Open **Terminal**: press ⌘ + Space, type `Terminal`, and press Enter.

		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
		```

		`curl` downloads the install script and `sh` runs it. macOS asks for your
		password. Nothing appears while you type it, which is normal.
	</TabItem>
	<TabItem label="Linux">
		Open a terminal.

		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
		```

		`curl` downloads the install script and `sh` runs it. You are asked for
		your password. Nothing appears while you type it, which is normal.
	</TabItem>
</Tabs>

The installer lists what it is about to do and asks
`Proceed with the install? [Y/n] (Enter = Yes)`. Press Enter.

The command installs Waired, starts it in the background, and then begins
sign-in in the same window. Leave the window open.

<Aside type="tip" title="Read the script before you run it">
	Each platform page shows how to download the script, read it, and run it
	yourself: [Windows](/getting-started/install/windows/#read-the-script-before-running-it),
	[macOS](/getting-started/install/macos/), [Linux](/getting-started/install/linux/).
</Aside>

## 2. Sign in with Google

When the install finishes, the same window prints a sign-in link and waits.

<Expected title="In the terminal">
```
Sign in using this link:
  https://app.waired.ai/login/…

Control Plane: https://app.waired.ai

>> Press Enter to open your browser (or open the link above yourself)...
```
</Expected>

Press Enter. Your browser opens. Choose your Google account. You can also
open the link yourself in any browser, on this computer or another one. The
terminal notices the sign-in either way.

<Aside type="note" title="On a computer with no desktop">
	There is no browser to open, so the terminal prints the link and says
	*“Nothing to press here — sign-in continues on its own once you open the
	link.”* Open the link on your phone or another computer. The terminal
	continues by itself.
</Aside>

After you sign in, the terminal shows:

<Expected>
```
Signed in as: you@example.com
Waired is signed in and running in the background.

>> Setup is continuing in your browser…
   Keep this terminal window open until setup finishes — it does the parts the
   browser can't.
   (press Enter to continue in the terminal instead)
```
</Expected>

<Aside type="caution" title="Leave this terminal window open">
	Installing the inference engine needs administrator rights, and a web page
	cannot grant them. The terminal does that work while the browser page shows
	the progress. If you close the terminal, the browser page says *“The setup
	command on … was closed before this finished. Your progress was saved.”* Run
	`waired init` to continue from where it stopped.

	When the terminal has finished its part, it says *“nothing more is needed
	from this terminal”*. You can close it after that.
</Aside>

## 3. Finish setup in the browser

Switch to the browser tab that opened. It shows the setup page for this
computer.

<Steps>

1. **Choose the inference engine.** **Ollama (standard)** is selected and
   works on any computer. Select **Next**. The page installs the engine and
   times this computer, which takes a few minutes.

2. **Pick a model.** The list is sorted with the recommended model first, and
   each entry says whether it fits this computer's memory. Keep the first
   entry unless you have a reason to change it. Select **Continue** to start
   the download.

3. **Wait for the steps to finish.**

   <Screenshot
   	src="setup-wizard-progress.png"
   	alt="The Waired setup page in a browser. The steps for the inference engine and the timing are complete, the model download is in progress with a size and a transfer rate, and the benchmark is waiting."
   	caption="You can close this tab. The download continues in the background."
   />

   | Step | What is happening | How long |
   |---|---|---|
   | **Download the inference engine** and **Install the inference engine** | The program that loads and runs models. Installing it is the part that needs administrator rights. | A few minutes |
   | **Download the small model used to time this computer** and **Time this computer** | A one-time measurement of how fast this computer answers. | A minute or two |
   | **Connect your coding tools** | Points Claude Code and the other tools you selected at Waired. | Seconds |
   | **Download the model** | The model weights, several gigabytes. The page shows the progress and the transfer rate. | 5 to 30 minutes |
   | **Benchmark the inference speed** | A short measurement with the model you chose. If this computer is too slow for it, the page offers a lighter model. | Up to 5 minutes |

4. **Finish.** When every step is complete, select **Finish setup** to open
   the list of your computers, or **Go to device** to open this computer's
   page.

</Steps>

<Expected>
	Every step shows a tick, and the page says
	**“Everything’s ready — my-desktop can now run models on its own.”**, with
	your computer's name in place of my-desktop.
</Expected>

<Expected tone="bad">
	*“To finish, run `sudo waired init` on this computer.”*

	The terminal that was doing the work is gone. Either it was closed, or it
	never had administrator rights. Open a terminal and run that command. Your
	progress is saved, and setup continues from where it stopped.
</Expected>

<details>
<summary>Set up in the terminal instead</summary>

At *“Setup is continuing in your browser…”*, press Enter. The terminal asks
you to confirm before it takes over:

```
   Taking over means this terminal drives setup and the browser page stops.
   Any model download keeps running either way.
   Take over setup in this terminal? [y/N] (default: No)
```

Answer `y`. Pressing Enter again answers No and leaves the browser in charge.

The terminal then asks whether to route Claude Code through Waired. Answer
`Y`. The model download runs with a progress bar:

```
Starting the inference engine…
Preparing to download qwen3.8-27b…
Downloading qwen3.8-27b: 41%  7.3 GB / 17.7 GB (44 MB/s)
```

When it finishes:

```
╭─ 🎉 Waired is ready — everything completed successfully! ─╮
│ Account   you@example.com                                 │
│ Model     qwen3.8-27b — 58 tok/s                          │
│ Claude    routed through Waired                           │
│ Local inference is live via the waired-agent daemon.      │
│ Point your coding agent at Waired and start building.     │
╰───────────────────────────────────────────────────────────╯
```

On a server with no desktop, the terminal is the only way. For details, see
[Set up in the terminal](/getting-started/set-up-in-the-terminal/).

</details>

## 4. Check that it works

<Tabs syncKey="mode">
	<TabItem label="In the Waired app">
		Select the **Waired icon**. It is in the menu bar on macOS, and next to
		the clock on Windows and Linux.

		<Screenshot
			src="app-ready.png"
			alt="The Waired app menu, showing a Connected status, the signed-in account, and an Inference item naming the running model."
			caption="Signed in, connected, and a model loaded."
			width="26rem"
		/>

		<Expected>
			The top of the menu says **Connected**, your email address is below
			it, and **Inference** names the model that is running.
		</Expected>
	</TabItem>
	<TabItem label="In the terminal">
		```sh
		waired infer "say hi"
		```

		<Expected>
			A greeting comes back within a few seconds. Your own computer produced
			it. Nothing was sent to a cloud provider.
		</Expected>
	</TabItem>
</Tabs>

<Aside type="note" title="If nothing comes back">
	Run [`waired doctor`](/getting-started/doctor/). It checks each part of the
	setup, marks it ✓, ⚠, or ✗, and repairs what it can when you press `f`. Most
	first-run problems end there.
</Aside>

## 5. Use it from Claude Code

Open Claude Code in any project. Type `/model` and select **Waired**, the row
described as *Any of your computers*. Then ask it something. The footer names
the model that answered.

<Screenshot
	src="claude-code-statusline.png"
	alt="The Claude Code footer with the Waired status line, naming the local model that answered the last request."
/>

<Expected>
```
⚡ waired: on Waired (qwen3.8-27b)
```
Your own computer answered with that model.
</Expected>

A session in which you have not chosen a model starts on Claude Code's own
default, which is an Anthropic model, and the footer says `→ waired: Anthropic`.
Waired does not change that default. `/model` switches in both directions: a
**Waired** row for your own computers, or an Anthropic model for the cloud. The
change applies from your next message.
