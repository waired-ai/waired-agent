"Turn it off for now" means five different things, with different
consequences. Find your row first.

| What you want | Do this |
|---|---|
| My coding tools should use the cloud for a while | [Pause routing](#pause-routing) |
| This computer should stop answering, but be ready again instantly | [Pause local inference](#pause-local-inference) |
| I need the memory back for something else | [Stop the engine](#stop-the-engine) |
| Nobody else should use this computer's model | [Stop sharing](#stop-sharing) |
| Take this computer off my network for a while | [Disconnect](#disconnect) |
| Remove Waired from this computer | [Uninstall Waired](/getting-started/uninstall/) |

## Pause routing

Your tools go back to talking to the cloud directly, as if Waired were not
installed. Nothing is uninstalled and nothing is forgotten.

```sh
waired pause
```

```sh
waired resume
```

The setting survives restarts. A paused computer is still paused tomorrow.

<Expected title="Confirming it took effect">
```sh
waired doctor
```
The **waired phase** line reads `paused` rather than
`active — overlay routing in effect`.
</Expected>

<Aside type="note" title="Paused means paused for everything">
	While paused, your own model does not answer either. `waired infer` and any
	chat app pointed at the local gateway get a "not available" response. To
	keep using your own model and only stop other computers from using it, see
	[Stop sharing](#stop-sharing).
</Aside>

## Pause local inference

This computer stops answering, but the model stays loaded in memory, so
resuming is instant. Requests from here go to one of your other computers. If
none of them can answer, the request fails and says so. Waired does not send
it to the cloud.

Select the **Waired icon**, then **Inference**, then **Pause local
inference**. The same item becomes **Resume local inference**.

This switch lives in the app only. `waired init --inference-enabled=false`
is the install-time version of it.

<Aside type="caution" title="This does not give the memory back">
	Pausing is a gate, not a shutdown. The engine keeps running and the model
	keeps its several gigabytes. To free memory, see
	[Stop the engine](#stop-the-engine).
</Aside>

## Stop the engine

Frees the memory the model is holding, usually several gigabytes, right now.
Settings are untouched, and starting the engine again reloads the model.

<Tabs syncKey="mode">
	<TabItem label="In the Waired app">
		Select the **Waired icon**, then **Inference**, then **Stop inference
		engine**. The same item becomes **Start inference engine**.
	</TabItem>
	<TabItem label="In the terminal">
		```sh
		waired inference engine stop
		waired inference engine start
		waired inference engine status
		```
	</TabItem>
</Tabs>

With the engine stopped, requests from this computer go to one of your other
computers if you have one, and otherwise fail until you start it again.

<Aside type="note" title="Unload keeps the computer answering">
	`waired inference unload`, or **Unload model (free memory)** in the app,
	also gives the model's memory back, but leaves the engine running. This
	computer keeps answering, and the next request loads the model again. Use
	it when you want the memory for a while but not the computer out of the
	way.
</Aside>

## Stop sharing

Your own use continues. Everyone else, your other computers and any public
guests, stops being able to use this computer's model, and work running for
them is cut off.

<Tabs syncKey="mode">
	<TabItem label="In the Waired app">
		Select the **Waired icon**, then **Inference**, then **Stop sharing this
		computer**.
	</TabItem>
	<TabItem label="In the terminal">
		```sh
		waired share off
		waired share on
		waired share status
		```
	</TabItem>
</Tabs>

This is the right setting for a workstation you do not want interrupted while
you still use its model yourself. For who the computer is offered to while
sharing is on, see [Share a computer with your other devices](/guides/sharing/).

<Aside type="note" title="Quitting the app pauses sharing on its own">
	**Quit** on the Waired icon stops the engine and stops all sharing for as
	long as the app is closed. Starting the app again puts everything back as
	it was. Quitting never changes the sharing setting itself.
</Aside>

## Disconnect

Takes the computer off your private network without signing out. Your other
computers stop seeing it, and it stops seeing them.

Select the **Waired icon**, then **Disconnect**. The same item becomes
**Connect**.

<Aside type="caution" title="Not the same as Sign out…">
	**Sign out…** removes this computer's identity, and signing back in adds it
	as a new device. **Disconnect** is one click each way and changes nothing
	permanent.
</Aside>

## Which one is on

```sh
waired status --observability
```

The output reports the phase, `active` or `paused`, whether the engine is
loaded, and whether this computer is offering its model to your others.

<Aside type="tip" title="Three switches people mix up">
	`waired pause` stops everything on this computer, routing and local
	inference alike. `waired inference off` decides whether this computer runs
	models at all, and it still uses your other computers' models when off.
	`waired share off` only stops other computers and guests from using this
	one's model, and `waired infer` still works here.
</Aside>
