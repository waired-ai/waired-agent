"Turn it off for now" means five different things in practice, and they have
different consequences. Find your row first.

| What you actually want | Do this |
|---|---|
| My coding tools should use the cloud again for a bit | [Pause routing](#pause-routing) |
| This computer should stop answering, but be instantly ready later | [Pause local inference](#pause-local-inference) |
| I need this memory back for something else | [Stop the engine](#stop-the-engine) |
| Stop anyone else using this one's model | [Stop sharing](#stop-sharing) |
| Take this computer off my network entirely | [Disconnect](#disconnect) |
| Remove Waired from this computer | [Uninstall](/getting-started/uninstall/) |

## Pause routing

Your tools go back to talking to the cloud directly, as if Waired were not
installed. Nothing is uninstalled and nothing is forgotten.

```sh
waired pause
```

```sh
waired resume
```

The setting survives restarts — a paused computer is still paused tomorrow.

<Expected title="Confirming it took effect">
```sh
waired doctor
```
The **waired phase** line reads `paused` rather than
`active — overlay routing in effect`.
</Expected>

<Aside type="note" title="Paused means paused for everything">
	While paused, your own model does not answer either — `waired infer` and any
	chat app pointed at the local gateway get a "not available" response. If you
	want your own model to keep working and only want to stop *other computers*
	using it, that is [stop sharing](#stop-sharing) instead.
</Aside>

## Pause local inference

This computer stops answering inference requests, but the model **stays loaded in
memory** — so resuming is instant. Requests from here go to one of your other
computers instead, or to the cloud.

Click the **Waired icon** → **Inference** → **Pause local inference**. The same
item becomes **Resume local inference**.

This one lives in the app only; there is no terminal equivalent. `waired init
--inference-enabled=false` is the install-time version of the same switch.

<Aside type="caution" title="This does not give the memory back">
	Pausing is a gate, not a shutdown: the engine keeps running and the model
	keeps its several gigabytes. If freeing memory is the point, use
	[Stop the engine](#stop-the-engine) below.
</Aside>

## Stop the engine

Frees the memory the model is holding — usually several gigabytes — right now.
Settings are untouched, and starting it again reloads the model.

<Tabs syncKey="method">
	<TabItem label="In the Waired app">
		Click the **Waired icon** → **Inference** → **Stop inference engine**.
		The same item becomes **Start inference engine**.
	</TabItem>
	<TabItem label="In a terminal">
		```sh
		waired inference engine stop
		waired inference engine start
		waired inference engine status
		```
	</TabItem>
</Tabs>

With the engine stopped, requests from this computer go to one of your other
computers if you have one, and otherwise fail until you start it again.

## Stop sharing

Your own use continues; everyone else — your other computers, and any public
guests — stops being able to use this one's AI, and work running for them is
cut off.

<Tabs syncKey="method">
	<TabItem label="In the Waired app">
		Click the **Waired icon** → **Inference** → **Stop sharing this
		computer**.
	</TabItem>
	<TabItem label="In a terminal">
		```sh
		waired share off
		waired share on
		waired share status
		```
	</TabItem>
</Tabs>

This is the right setting for a workstation you do not want interrupted, while
still using your own model yourself.

<Aside type="note" title="Quitting the app pauses sharing on its own">
	**Quit** on the Waired icon stops the engine and stops all sharing — nobody
	is sent work here for as long as the icon is closed. Starting the icon
	again puts it back exactly as you had it — quitting never changes the
	sharing setting itself.
</Aside>

<Aside type="tip" title="Stopping only some of it happens in the console">
	This switch is all or nothing. To keep serving your own computers but stop
	public guests — or the other way round — use the **Sharing** card on the
	computer's page in the [web console](/guides/web-console/), which decides
	*who* the computer is offered to. [Public share](/public-share/) explains
	what sharing with other Waired users means.
</Aside>

## Disconnect

Takes the computer off your private network without signing out. Your other
computers stop seeing it, and it stops seeing them.

Click the **Waired icon** → **Disconnect**. The same item becomes **Connect**.

<Aside type="caution" title="Not the same as Sign out…">
	**Sign out…** removes this computer's identity, and signing back in enrolls it
	as a new device. **Disconnect** is one click each way and changes nothing
	permanent. See [The Waired app](/guides/waired-app/#settings).
</Aside>

## Which one do I have on?

```sh
waired status --observability
```

It reports the phase (active or paused), whether the engine is loaded, and
whether this computer is offering it to your others.
