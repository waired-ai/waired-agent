Waired connects OpenClaw to the model on your own computer through a small
plugin in your home folder. Setup installs it if you said yes to the
coding-tool question. This page covers installing it yourself, what it
changes, and how to remove it.

## Connect OpenClaw

```sh
waired link openclaw
```

That is the whole setup. Start OpenClaw as usual afterwards and pick the
Waired model.

<Expected>
	OpenClaw's model picker lists one new entry:

	| Model | What it uses |
	|---|---|
	| `waired/default` | Whichever model Waired is running here |
</Expected>

No API key and no environment variable are involved. Waired connects OpenClaw
to the model on your own computer directly.

<Aside type="note" title="Your own default model is not touched">
	Linking adds the Waired model to the list you can choose from. Which model
	OpenClaw starts with stays as you had set it. Switch to the Waired model
	when you want it.
</Aside>

<Aside type="tip" title="Several coding tools installed">
	`waired link` with no name sets up every tool it finds: Claude Code,
	OpenCode, and OpenClaw.
</Aside>

## What it changed

Two things, both inside your own home folder:

| Path | What it is |
|---|---|
| `~/.openclaw/plugins/waired/` | A small plugin that knows how to reach your model |
| `~/.openclaw/openclaw.json` | Two settings that switch that plugin on, and the model above added to the list |

Nothing else in that file is modified, and nothing outside your home folder
is touched.

If you already had an `openclaw.json`, Waired copies it before the first
change it makes, to `~/.openclaw/openclaw.json.waired-bak-<timestamp>`.
Writing the file back drops your key order and formatting, so that copy is
the only record of the file as you wrote it. Running `waired link openclaw`
again when nothing needs changing leaves the file, its timestamp, and that
copy as they are.

## How much context OpenClaw is told about

The plugin records how long a prompt this computer can take, so OpenClaw does
not start shortening your conversation earlier than it has to.

That number comes from the computer itself, so it is known only once a model
is loaded. During first-time setup it usually is not, so the plugin says
nothing about it and OpenClaw uses its own default. Setup fills it in on its
way out and says so:

```
OpenClaw now knows this computer serves 200704 tokens of context.
```

The number changes when you change model, so it can fall behind what this
computer serves today. `waired doctor` says when it has:

```
! openclaw context window   the plugin declares 200704 tokens; this computer now serves 124928
```

Press `f` to bring it up to date.

## Check it or remove it

[`waired doctor`](/getting-started/doctor/) verifies the whole path: the
connection, whether routing is paused, and whether a model is loaded. It
repairs what it can when you press `f`.

To remove the integration:

```sh
waired unlink openclaw
```

It undoes what `waired link` added and nothing else. The copy of your original
`openclaw.json` stays where it is, and `waired unlink` prints the path.

You can also see and reapply the integration from the Waired app. Select the
**Waired icon**, then **Settings**, then the **OpenClaw** entry.
