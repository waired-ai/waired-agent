## Connect it

```sh
waired link openclaw
```

That is the whole setup. Start OpenClaw as usual afterwards and pick one of the
Waired models.

<Expected>
	OpenClaw's model picker lists one new entry:

	| Model | Use it for |
	|---|---|
	| `waired/default` | Whichever model Waired is running here |
</Expected>

No API key and no environment variable are involved. Waired connects OpenClaw
to the AI running on your own machine directly.

<Aside type="note" title="Your own default model is not touched">
	Linking adds the Waired models to the list you can choose from. Which model
	OpenClaw starts with stays whatever you had set — you switch to a Waired one
	when you want it.
</Aside>

<Aside type="tip" title="Have several coding tools installed?">
	`waired link` with no name sets up every one it finds — Claude Code, OpenCode
	and OpenClaw.
</Aside>

## What it changed

Two things, both inside your own home folder:

| Path | What it is |
|---|---|
| `~/.openclaw/plugins/waired/` | A small plugin that knows how to reach your AI |
| `~/.openclaw/openclaw.json` | Two settings that switch that plugin on, and the model above added to the list |

Nothing else in that file is modified, and nothing outside your home folder is
touched.

If you already had an `openclaw.json`, Waired copies it before the first change
it makes, to `~/.openclaw/openclaw.json.waired-bak-<timestamp>` — writing the
file back drops your key order and formatting, so that copy is the only record
of it as you wrote it. Running `waired link openclaw` again when nothing needs
changing leaves the file, its timestamp, and that copy exactly as they are.

## How much context it is told about

The plugin records how long a prompt this computer can actually take, so
OpenClaw does not start shortening your conversation earlier than it has to.

That number comes from the computer itself, so it is only known once a model is
loaded. During first-time setup it usually is not yet — the plugin then says
nothing about it, and OpenClaw uses its own default. Setup fills it in on its
way out, and says so:

```
OpenClaw now knows this computer serves 200704 tokens of context.
```

The number moves when you change model, so it can fall behind what this
computer serves today. `waired doctor` says when it has:

```
! openclaw context window   the plugin declares 200704 tokens; this computer now serves 124928
```

Press **f** to bring it up to date.

## Check it, or remove it

[`waired doctor`](/getting-started/doctor/) verifies the whole path — the
connection, whether routing is paused, whether a model is loaded — and repairs
what it can when you press **f**.

To remove the integration:

```sh
waired unlink openclaw
```

It undoes what `waired link` added and nothing else. The copy of your original
`openclaw.json` stays where it is — `waired unlink` prints the path — so it is
yours to keep or delete.

You can also see and re-apply it from the Waired app — click the **Waired
icon** → **Settings** → **OpenClaw**.
