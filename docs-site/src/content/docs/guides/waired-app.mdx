This page is the reference for the Waired app's menu, in the order the items
appear. For where the icon is and how to read its first lines, start with
[Meet the Waired app](/getting-started/meet-the-app/).

## The top line

The first line reports the state of everything else. If it is not
**Connected**, nothing below it works as described.

| Top line | Meaning | What to do |
|---|---|---|
| **● Connected** | Signed in and reachable. | Nothing. |
| **◐ Connecting…** | Working on it, just after you sign in or wake the computer. | Wait a few seconds. |
| **○ Not signed in** | Waired is installed but has no account yet. | Select **Sign in…** below it. |
| **◐ Signing in…** or **◐ Activating…** | A sign-in you started is in progress. | Finish it in the browser window that opened. |
| **○ Disconnected** | Signed in, but not reaching the network right now. | Select **Connect**. If that does not help, see [Troubleshooting](/troubleshooting/). |
| **◐ Waired agent is starting…** | Normal just after you log in. On Windows the background service starts a couple of minutes after the icon. | Wait, or select **Start the Waired agent…**. |
| **⚠ Waired agent is not running** | The background service should be up and is not. | Select **Start the Waired agent…**. Your computer asks for administrator access. See [Nothing answers](/troubleshooting/no-answer/#the-waired-icon-says-the-agent-is-not-running). |
| **◐ Reconnecting to the Waired agent…** | The service is running but has not answered yet. You are still signed in. | Wait. It is usually brief. |

When something needs your attention, the first line says what instead of
**Connected**:

| Top line | Meaning | What to do |
|---|---|---|
| **⚠ No engine is answering** | Nothing can serve a request. No model runs on this computer, and none of your other computers is reachable. A Claude Code turn on a Waired row fails and says so. | Start an engine here with **Inference**, then **Start inference engine**, or turn on a computer that runs one. |
| **⚠ Claude Code not served (…)** | The background service is stopped or paused, so Waired is not answering anything. | See [Nothing answers](/troubleshooting/no-answer/). |
| **⚠ OpenCode integration needs attention** or **⚠ OpenClaw integration needs attention** | That tool's config file no longer points at Waired. | Select **Settings**, then **Reconfigure…** for the tool named. |
| **⚠ Inference fell back recently** | A request in the last 10 minutes could not be served the way you asked. | **Settings**, then **Recent activity** lists them. |

The same line is the icon's tooltip. Hover over the icon to read it without
opening the menu.

## Notices

Under the top line, Waired adds a row for anything it has to tell you about
this computer. Warnings (⚠) come before notes (⬆). A notice stays as long as
it is true and goes on its own when it stops being true. For every notice and
what to do about it, see [Notices](/guides/notices/).

## The status lines

Three lines under the connect item answer "is this working" without opening
a submenu.

| Line | Meaning |
|---|---|
| **● Engine: ready — Qwen3 8B Instruct** | This computer runs that model and answers requests with it. |
| **● Engine: ready — Qwen3 8B Instruct (not loaded)** | Same, but the model is not in memory at the moment. The next request waits for it to load, usually 20 seconds to a minute. It stays loaded afterwards for as long as **Keep-alive** says. |
| **◐ Engine: downloading — …** | The model file is still arriving over the network. |
| **○ Engine: off on this computer** | Local inference is switched off here. Requests go to your other computers. |
| **○ Engine: none on this computer** | No inference engine is installed here. Normal for a computer you only send requests from. |
| **○ Engine: stopped (memory freed)** | You stopped the engine to get its memory back. **Inference**, then **Start inference engine** brings it back. |
| **⚠ Engine: engine failed** or **⚠ Engine: pull failed** | The engine could not start, or the download failed. **Inference** has the reason. |
| **● Peers: 2 of 4 serving** | How many of your other computers can answer this one's requests right now. |
| **● Claude Code: routed through Waired** | Claude Code on this computer sends its requests through Waired. |
| **○ Claude Code: not routed through Waired** | Claude Code talks to the Anthropic API directly. Run `sudo waired claude enable` to change that. |
| **⚠ Claude Code: routed elsewhere (…)** | Something else has set `ANTHROPIC_BASE_URL` on this computer. Waired does not overwrite it. |

A line is absent when the background service is too old to report it. Select
any of them, or any other line in the menu that reports a state, to open
[Status…](#status).

## The account line

Under the top line is the account you are signed in as. Selecting it opens
that account's page in the [web console](/guides/web-console/).

## Sign in, Connect, and Disconnect

The item under the status lines changes with the state:

- **Sign in…** starts sign-in. Your browser opens for a Google account.
- **Disconnect** takes this computer off your private network without
  signing out. Requests stop being routed. Use it when you want your tools
  to go back to the cloud for a while.
- **Connect** puts it back.

<Aside type="caution" title="Signing in here does not finish a first-time setup">
	On a computer that has never been set up, installing the inference engine
	needs administrator rights, which the app cannot grant. Signing in from
	the icon reaches the setup page and then asks you to run `waired init`
	in a terminal. For a first install, follow the [Quickstart](/quickstart/).
</Aside>

## Models

The **Engine** line above names the model that runs now. The **Models**
submenu lists what this computer can run. Select one to switch to it. The
change applies live. The engine reloads in a few seconds and keeps serving.
If that model has not been downloaded yet, the download starts and the old
model keeps answering until the new one is ready. **Other quantizations**
lists the other builds of the same models. For when to go bigger or smaller,
see [Change the model](/guides/choose-a-model/).

## Inference

**Inference** holds the controls for the engine on this computer. Where your
requests go is the next submenu, **Inference routing**.

| Item | What it does |
|---|---|
| **Pause local inference** or **Resume local inference** | Whether this computer answers requests. Paused, it can still use your other computers, and the model stays loaded, so resuming is instant. |
| **Run models on this computer** | The same switch, worded for a computer that has never run one. Choosing it installs the engine and downloads the model. |
| **Start inference engine** or **Stop inference engine** | Stops the engine right now to free memory, several GB, without changing any setting. Starting it again reloads the model. |
| **Install Ollama…** | Appears when no inference engine is installed yet. |
| **Share this computer** or **Stop sharing this computer** | Whether this computer lends itself out at all, to your other computers and to public guests alike. Off, you can still use it yourself. |
| **Sharing: enabled**, **disabled**, **paused**, or **nobody, set in the console** | What is happening. **enabled**: this computer is serving others. **disabled**: you turned sharing off. **paused**: sharing is withheld while the app is closed. **nobody, set in the console**: the switch is on, but the console has taken this computer out of every distribution. Who it is offered to is set in the [web console](/guides/web-console/). |
| **Active: …** or **Model not loaded** | The model in use, and whether it is in memory. While this computer is working, the row also says how many requests it is on. |
| **Unload model (free memory)** | Gives the model's memory back while the engine keeps running. The next request loads the model again. Greyed out when there is nothing to give back. |
| **Keep-alive: …** | How long the model stays in memory after your last request: **Always**, **15 minutes**, **1 hour**, or **8 hours**. The default is **Always**, because reloading a model costs the next request a noticeable wait. |

<Aside type="note" title="Pause, Unload, and Stop are three different things">
	**Pause local inference** stops answering and keeps the model in memory.
	**Unload model** gives the memory back and keeps answering. **Stop
	inference engine** does both. To free several GB and keep working, you
	want Unload. See [Pause or stop Waired](/guides/pause/).
</Aside>

On a computer whose engine keeps the model for exactly as long as it runs,
**Unload model** and **Keep-alive** are left out. **Stop inference engine** is
how you free the memory there.

## Inference routing

Which of your computers answers when you ask something on this one. The top
of the submenu shows the current answer, **Worker: auto** or the pinned
computer, and whether any of your other computers' engines is reachable.
Below are the routing mode, the preference, the smallest model to route to,
and the computers you can pin. For what each one does, see
[Choose which computer answers](/guides/routing/).

## Public computers

**Use public computers** decides whether your requests may run on computers
other Waired users are lending out: **Always allow public computers**, **Use
only when better than my own computers**, or **Do not use public computers**.
It is off unless you turn it on, and the first time you turn it on Waired
asks you to read and accept a warning. **Privacy & safety…** opens that
page. Sharing your own computer publicly is not in this menu. It is turned on
and off in the web console. See [Public Share](/public-share/).

## Claude Code

The submenu says whether Claude Code on this computer is pointed at Waired:
**Claude integration: ● active** when it is, and a row with the command that
turns it on when it is not. Where each turn runs is not chosen here. It is
the model you pick in Claude Code's `/model`. See
[Use Waired from Claude Code](/guides/claude-code/).

## This device

Your computer's name on the network, its Waired address (select to copy),
the network it belongs to, and your other computers, one line each:

| Line | Meaning |
|---|---|
| **● sv-evox2 — qwen3.6-35b-a3b** | That computer can answer this one's requests, running that model. |
| **○ sv-xps15 — no engine** | It cannot, and why. Other reasons are **unavailable** (it has not reported in recently), **awaiting model**, **downloading**, **pull failed**, and **engine failed**. |

A computer someone else shares with you publicly appears under the name that
share gives it, never its own. Selecting any of these lines opens
[Status…](#status).

## Status…

Everything Waired knows right now, in one window. For the sections and what
**Copy details** adds, see [The Status… report](/guides/status-report/).

## Open Admin Console…

Opens the [web console](/guides/web-console/), signed in: your device list,
setup pages, public-share settings, and account.

## Settings

| Item | What it does |
|---|---|
| **OpenCode** and **OpenClaw** | Whether each coding tool is configured to use Waired, and where its config file is. **Reconfigure…** runs `waired link opencode` or `waired link openclaw` after a confirmation. |
| **Recent activity** | Requests in the last 10 minutes that could not be served the way you asked. Empty is normal. Each line reads `<model> — <from> → <to> (<reason>, <how long ago>)`. |
| **About Waired** | Version information. |
| **Notify me about updates** | Whether a pop-up appears when a new version is out. The **Update available** row in the menu stays either way, so turning this off stops the interruption, not the update. |
| **Start Waired on login** | Whether the app starts when you log in to your computer. Turning it off does not stop the background service. |
| **Sign out…** | Signs this computer out and removes its identity. It leaves your network. To use it again you sign in from scratch. |

<Aside type="caution" title="Sign out… is not the same as Disconnect">
	**Disconnect** is temporary and reversible in one click. **Sign out…**
	removes this computer's identity, and the next sign-in adds it as a new
	device. To stop using your own model for a while, use **Disconnect** or
	[pause routing](/guides/pause/).
</Aside>

## When an update is available

An **⬆ Update available — install …** row appears in the notices. Selecting
it asks for administrator rights and updates in place. When the update
finishes, the app comes back on the new version. See
[Update Waired](/getting-started/update/).

## Quit

**Quit** closes the app and winds this computer down. The inference engine
is stopped, so its memory comes back, and all sharing stops for this session.
Your other computers and public guests stop being sent work here while nobody
is at the keyboard. Waired itself keeps running in the background, and your
coding tools keep working through one of your other computers, or the cloud.
Logging out of your computer, or shutting it down, does the same.

Nothing is forgotten. Your sharing setting is untouched. Start the app again
and this computer offers its model as before.

To bring the app back, start Waired from your applications list, or log out
and back in when **Start Waired on login** is on.

<Expected tone="bad" title="The icon is missing entirely">
	Waired is installed but the icon is not showing. On Windows, check the
	**^** hidden-icons arrow first. Otherwise start the Waired app from your
	applications list. On a Mac, that is **Waired** in Launchpad. On Linux, a
	desktop with no support for icons next to the clock needs an extension.
	See [Install on Linux](/getting-started/install/linux/#the-icon-on-gnome).
	The background service is unaffected either way, and `waired status` in a
	terminal still reports a working setup.
</Expected>
