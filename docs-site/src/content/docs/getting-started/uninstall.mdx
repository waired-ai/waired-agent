Removing Waired takes about ten seconds and leaves nothing running in the
background. Decide first whether to keep your settings and downloaded models.

## Which removal you want

|  | **Remove the app** | **Remove everything** |
|---|---|---|
| Waired app and background service | closed and removed | closed and removed |
| Claude Code and coding-tool setup | removed | removed |
| This computer in your device list | removed | removed |
| Your settings and this device's identity | **kept** | deleted |
| Downloaded models (several GB) | **kept** | deleted |
| Reinstalling later | signs in fresh | signs in fresh |

Pick **Remove the app** unless you are short on disk space or handing the
computer to someone else.

## Remove the app

<Tabs syncKey="os">
	<TabItem label="Windows">
		If you installed with the setup program, remove Waired the normal Windows
		way: **Settings > Apps > Installed apps > Waired > Uninstall**.

		<details>
		<summary>Remove it with a command instead</summary>

		```powershell
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.ps1 | iex
		```

		This works however Waired was installed, including with the setup
		program.

		</details>
	</TabItem>
	<TabItem label="macOS">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.sh | sh
		```
	</TabItem>
	<TabItem label="Linux">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.sh | sh
		```
	</TabItem>
</Tabs>

The uninstaller lists what it is about to remove and asks
`Proceed with the uninstall? [y/N]`. Pressing Enter cancels. Type `y` to go
ahead.

If the Waired app is open, the uninstaller closes it first and prints a line
naming the app and its process id:

```
[waired] Stopping the Waired app (waired-tray, PID 4321)
```

At the end it says:

```
[waired] Waired removed. Local config and state were kept; re-run with --clean to wipe them.
```

<Aside type="tip" title="See what it would do first">
	Add `--dry-run` (`-DryRun` on Windows). The uninstaller prints every step
	without changing anything.
</Aside>

## Remove everything, including models

This also deletes your settings, this device's identity, and Waired's copy of
the inference engine with every model you downloaded. It cannot be undone.

<Tabs syncKey="os">
	<TabItem label="Windows">
		```powershell
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.ps1 -OutFile $env:TEMP\uninstall.ps1
		& $env:TEMP\uninstall.ps1 -Clean
		```

		Two lines, because the one-line form cannot pass the `-Clean` option.
	</TabItem>
	<TabItem label="macOS">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.sh | sh -s -- --clean
		```
	</TabItem>
	<TabItem label="Linux">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/uninstall.sh | sh -s -- --clean
		```
	</TabItem>
</Tabs>

<Aside type="note" title="An Ollama you installed yourself">
	Waired keeps its own copy of the inference engine inside its own folder, so
	removing Waired removes that copy. A separate Ollama that you installed
	yourself is treated differently on each system:

	- **macOS**: an **Ollama** in your Applications folder is never touched.
	  Drag it to the Trash if you want it gone, and delete `~/.ollama` for the
	  models it downloaded.
	- **Windows**: removing everything means exactly that. An Ollama in
	  `Program Files` or in your user folder is removed too, with its models.
	  Use the plain uninstall above to keep it.
	- **Linux**: the same as Windows. An Ollama installed system-wide is
	  removed.
</Aside>

## After you uninstall

- **Your other computers are unaffected.** They stay in your network and keep
  working. If this computer was the one running the model, the others have no
  model to reach until you set another one up.
- **The device disappears from your account.** If the computer was offline
  when you uninstalled, it may still be listed. Remove it from the device list
  at [app.waired.ai](https://app.waired.ai).
- **Nothing is billed.** Waired never charged per message.

## Claude Code says Connection refused after Waired is gone

If Waired was removed some other way, for example deleted by hand, removed
with `apt remove waired`, or removed by an older uninstaller, Claude Code's
machine-wide settings can still point at Waired. Every request then fails
with:

```
API Error: Connection refused — a firewall or proxy may be blocking it (ConnectionRefused)
```

Run the uninstall command from [Remove the app](#remove-the-app) again. It
finds and removes the leftover Claude Code settings even though the `waired`
program is gone, and ends with:

```
[waired] Waired wasn't installed, but Claude Code still had Waired's settings. They were removed. Restart Claude Code for the change to take effect.
```

Then restart Claude Code.

On Linux, the uninstaller needs `python3` to edit the settings file. Without
it, the file is left alone and the uninstaller warns:

```
[waired] Warning: /etc/claude-code/managed-settings.json may still point Claude Code at Waired, and there's no python3 on this computer to check it. Remove Waired's settings from it by hand.
```

To fix it by hand, open the file as an administrator and remove two things:
`ANTHROPIC_BASE_URL` if its value starts with `http://127.0.0.1:`, and any
hook whose command contains `waired claude`. Leave everything else in the
file as it is, then restart Claude Code.

| | Managed settings file |
|---|---|
| Windows | `C:\Program Files\ClaudeCode\managed-settings.json` |
| macOS | `/Library/Application Support/ClaudeCode/managed-settings.json` |
| Linux | `/etc/claude-code/managed-settings.json` |

## Start over on the same computer

To wipe and reinstall in one step, run the installer with the clean option.
It does the full wipe above and then installs fresh.

<Tabs syncKey="os">
	<TabItem label="Windows">
		```powershell
		$env:WAIRED_CLEAN = '1'
		iwr -useb https://github.com/waired-ai/waired-agent/releases/latest/download/install.ps1 | iex
		```

		Expect two permission prompts, one for the wipe and one for the install.
	</TabItem>
	<TabItem label="macOS">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh -s -- --clean
		```
	</TabItem>
	<TabItem label="Linux">
		```sh
		curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh -s -- --clean
		```
	</TabItem>
</Tabs>

The installer asks you to confirm before wiping. Because the wipe deletes this
device's identity, the sign-in afterwards adds it back as a new device.
