Waired installs with one command on all three platforms. You paste a line into
a terminal, the installer shows what it will do, and you confirm. On Windows
you can also use a setup program that you double-click.

## System requirements

| Role | What works |
|---|---|
| **Runs the model** | Ubuntu 24.04 or later, Debian trixie or later, Windows 11, Windows Server 2025, macOS 13 or later. Apple Silicon recommended on a Mac. |
| **Uses the model** | Any of the above. No GPU needed. |

A GPU makes answers much faster, and a recent processor runs a small model at
a usable speed. The computer you type on needs nothing special.

The [model catalog](/reference/model-catalog/) lists the memory each model
needs. You do not have to read it before you install. Setup picks a model that
fits this computer.

## What the installer puts on your computer

- **Waired.** A background service that keeps this computer connected, and the
  `waired` command. The service starts with the computer, before anyone logs
  in.
- **The Waired app.** An icon in the menu bar on macOS, and next to the clock
  on Windows and Linux, for everyday controls.

The inference engine is not part of the install. It is a download of several
gigabytes, and setup installs it later, only if you choose to run models on
this computer.

Every installer prints a summary of what it is about to do and asks
`Proceed with the install? [Y/n] (Enter = Yes)` before it changes anything.

<Aside type="tip" title="If you have never used a terminal">
	Each platform page starts by telling you how to open a terminal, and each
	command comes with a sentence saying what it does. After this one command,
	you can do everything else from a browser and the Waired app.
</Aside>
