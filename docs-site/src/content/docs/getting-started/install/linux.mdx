The one-line installer supports Ubuntu 24.04 and later and Debian trixie and
later, on 64-bit x86 and ARM. It adds Waired's apt repository, so updates
arrive the same way as the rest of your system packages.

## Install

<Steps>

1. Open a terminal and run:

   ```sh
   curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
   ```

   `curl` downloads the install script and `sh` runs it.

2. Read the summary and press Enter at
   `Proceed with the install? [Y/n] (Enter = Yes)`.

3. Enter your password when asked. Nothing appears while you type it, which
   is normal.

</Steps>

The installer then starts sign-in in the same window. Continue with
[Sign in](/getting-started/sign-in/).

<Aside type="tip" title="Read the script before running it">
	Download the script, read it, and then run it:

	```sh
	curl -fsSLO https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh
	less install.sh    # press q to quit
	sh install.sh
	```
</Aside>

## Other distributions

The installer only knows how to set up apt repositories, so Fedora, Arch,
Alpine, and other distributions are not covered yet. You can still run Waired
by taking the programs from the
[latest release](https://github.com/waired-ai/waired-agent/releases/latest)
and registering the service yourself. Nothing on that path is automated, and
updates are manual.

## The icon on GNOME

GNOME does not show icons next to the clock without an extension, so Waired's
icon needs the AppIndicator extension. Setup installs and enables one when it
finds GNOME on the computer, and Waired checks again each time you log in. If
the extension is ever turned off, Waired turns it back on. If the icon still
does not appear, run `waired doctor --fix`, or see
[The Waired icon is missing](/troubleshooting/other-computers/#the-waired-icon-is-missing-on-linux).
KDE Plasma needs nothing. Computers without a desktop are left alone.

## Skip the inference engine

Waired installs [Ollama](https://ollama.com), the inference engine, during
setup, and only on computers that will run models. To make sure it is never
installed:

```sh
curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh -s -- --skip-ollama
```

You can add it later with `sudo waired runtimes install ollama`.

## What gets installed

| | |
|---|---|
| Packages | `waired` and `waired-tray`, from Waired's apt repository |
| Background service | `waired-agent.service` (systemd), starts at boot |
| Settings | `/etc/waired` |
| State | `/var/lib/waired` |
