Waired runs on macOS 13 (Ventura) and later. If this Mac will run the model,
Apple Silicon is strongly recommended. Its unified memory is what lets a laptop
hold a useful model.

<Aside type="note" title="Installing is one Terminal command">
	There is no disk image or Homebrew formula yet, and the programs are not
	code-signed. Both are planned. The command below puts **Waired** in your
	Applications folder.
</Aside>

## Install

<Steps>

1. Open **Terminal**. Press ⌘ + Space, type `Terminal`, and press Enter.

2. Paste this line and press Enter.

   ```sh
   curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh
   ```

   `curl` downloads the install script and `sh` runs it.

3. Read the summary and press Enter at
   `Proceed with the install? [Y/n] (Enter = Yes)`.

4. Enter your Mac password when asked.

   Nothing appears while you type it. That is how Terminal handles passwords.
   Type the password and press Enter.

   Waired asks for the password because the background service is registered
   for the whole Mac, so it starts at boot without anyone logging in.

</Steps>

The installer then starts sign-in in the same window. Continue with
[Sign in](/getting-started/sign-in/).

<Aside type="tip" title="Read the script before running it">
	Download the script, read it, and then run it:

	```sh
	curl -fsSLO https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh
	less install.sh    # press q to quit
	sh install.sh
	```
</Aside>

## Skip the inference engine

Waired installs [Ollama](https://ollama.com), the inference engine, during
setup, and only on computers that will run models. To make sure it is never
installed:

```sh
curl -fsSL https://github.com/waired-ai/waired-agent/releases/latest/download/install.sh | sh -s -- --skip-ollama
```

You can add it later with `sudo waired runtimes install ollama`.

## What gets installed

| | |
|---|---|
| Commands | `/usr/local/bin/waired`, `/usr/local/bin/waired-agent` |
| The Waired app | `/Applications/Waired.app`, the menu bar icon |
| Background service | A system `launchd` daemon, starts at boot |
| Settings and state | `/Library/Application Support/waired` |
| Inference engine and models | Inside `/Library/Application Support/waired`, only on a computer that runs models |

The installer opens the Waired app for you, and the app opens at every login
after that. If you installed over SSH, there is no desktop session to open it
in. Open **Waired** from Launchpad once, and it starts at every login after
that.

The inference engine is the one thing that does not go in the Applications
folder. Waired keeps its own copy next to its settings. Nothing outside the
locations above is touched. If you already have Ollama on this Mac, Waired
leaves it as it is and does not use it.
