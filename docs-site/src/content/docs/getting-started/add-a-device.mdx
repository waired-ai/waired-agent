Once one computer runs the model, every other computer you sign in on can use
it, at home, at the office, or on café Wi-Fi. Signing in with the same Google
account is what puts them on the same private network. There is nothing to
pair and no address to copy.

## On the new computer

<Steps>

1. **Install Waired.** See [Install on Windows](/getting-started/install/windows/),
   [Install on macOS](/getting-started/install/macos/), or
   [Install on Linux](/getting-started/install/linux/).

2. **Sign in with the same Google account** you used on the first computer.
   The installer starts sign-in for you.

3. **Choose not to run models here**, unless this computer is also powerful
   enough to host one. In the browser, choose **Don't run local inference on
   this computer**. In the terminal, answer `n` to *Run models on this
   computer?*. A laptop that only uses the model downloads nothing. The
   computer you set up first answers for it.

</Steps>

## Check that it reaches the first computer

```sh
waired status --observability
```

Read the **Mesh** line:

```
Mesh:     2 enrolled / 1 reachable / 1 ready
```

- **enrolled** is how many computers are in your network.
- **reachable** is how many this computer can talk to right now.
- **ready** is how many of those have a model loaded and are offering it.

`1 reachable / 1 ready` on a laptop means the computer running your model is
up and available. If the line reads `0 reachable`, see
[My other computer cannot reach the model](/troubleshooting/other-computers/#my-other-computer-cannot-reach-the-model).

Then ask it something:

```sh
waired infer "say hi"
```

The answer comes from the other computer, over an encrypted connection.

## Which computer answers

By default Waired chooses for you. It uses this computer's own model if there
is one, and otherwise asks one of your other computers. To always use a
specific computer, or to prefer one, see
[Choose which computer answers](/guides/routing/).

<Aside type="note" title="Nothing to open on your router">
	Your computers connect directly when the network allows it, and fall back to
	an encrypted relay when a firewall gets in the way. Both are automatic. You
	do not forward ports or configure a VPN.
</Aside>

## Remove a computer later

Uninstalling Waired on a computer removes it from your list. To remove one
you no longer have access to, open the device list at
[app.waired.ai](https://app.waired.ai) and delete it there.
