# カタログは参照機で動かしたものに限り、枝刈りしたビルドは入れず、量子化していない variant は推測の速さで添える (20260920 03:00)

## Status

Accepted。オーナー判断 2026-09-19〜20（waired-ai/waired#1427、comment 5744102939）。

次の記録を**部分的に狭め、例外を 1 つ足す（覆さない）**。

- `docs/decisions/20260916/0340-catalog-reference-host-rank-and-admission.md` の決定 3（入れる条件は「参照機で 200k 込みの完全常駐」）について:
  - 載るという計算だけでは足りず、実際に参照機で動かしたことを条件にする（決定 1）。
  - 量子化していない variant は、この条件の例外として入れる（決定 3）。
  - 0340 の `## Status` に、鏡の一文を置いた。

## Context

- waired-ai/waired#1427 で、glm-5.2 と deepseek-v4-flash の代わりに参照機（Strix Halo、128 GB のユニファイドメモリ）に載る大型モデルを探した（2026-09-19）。
  - 最初は、速さの線（190 秒）も入れる条件のように扱い、線を超える候補を外していた。
  - オーナーの答え:
    > 速度的なラインについて深く考える必要はないです。あくまでsv-evox2でやっているのはモデル間の重さ比較であり、これで動かすことを前提とはしていません。なので、とりあえずメモリに乗って動けばそれでcatalogに入れる基準としてはOKです。
- 参照機で、製品の固定版の ollama 0.34.0 を使って 4 モデルを読み込んだ。200,704 のコンテキストウィンドウで、短い要求、tool call とその続き、約 27k トークンの要求まで、すべて通った（waired-ai/waired#1427、comment 5742557353）。
  - 4 モデルは、DeepSeek-V4-Flash-0731 の枝刈り版 Q3_K_M、Ling-3.0-flash i1-Q4_K_S、Step-3.7-Flash UD-IQ3_XXS、Laguna S 2.1 UD-Q4_K_XL。
  - 結果を受けたオーナーの判断:
    > やりたこととしては、catalogに入れるモデルは動作を検証したものにし、また、その速度をある程度実測して、いわゆるspeed tierリストを作ることが目的でした。そういう観点から、枝狩り版は別モデルみたいになるしやめときましょうか。そのうえで、量子化していないものについてもcatalogには一応含めてはどうでしょうか。speed tierは量子化していないものに比べてちょっとだけ高いものにしましょう（未実測ではあることはどこかにメモしたうえで）

    > いれましょう。合わせてYaRNにより1Mが出せるモデルについては、1Mで選択されたときにいちおう警告を出した上で出したいです。これは既存のqwenモデルたちについても同様です

## Decision

1. **カタログに入れるのは、参照機で動作を確かめた variant だけ。**
   - 確かめる中身: 200,704 のコンテキストウィンドウで読み込めて、応答と tool call が返ること。
   - 速さは、参照機で製品の計測を繰り返して `internal/catalog/turnspeeds.json` に記録する（0340 の決定 2）。
   - 速さの線（`hostfit.ModelTurnBudgetSeconds`）は、入れる条件ではない。参照機での秒数は、モデルどうしの重さを比べるために使う。
2. **エキスパートを枝刈りしたビルド（REAP など）は入れない。** 元のモデルのエキスパートを取り除いたものは、そのモデルの variant ではなく、別のモデルに近いため。
3. **量子化していない variant は、決定 1 の例外として入れる。**
   - 対象: 配布元が出した元の精度の variant（BF16 / F16 など）。同じモデルの量子化 variant が決定 1 を満たしている場合に限る。参照機に載らなくてよい。
   - 参照機での秒数: 同じモデルの量子化 variant の実測値 × 1.1 の推測値を置く。
     - `turnspeeds.json` の記録は `method: estimate` で、`notes` に未実測であることを書く。
     - ×1.1 は、オーナーの「ちょっとだけ高いもの」を数にしたもの。
   - 入れる条件のテスト（`internal/hardware/catalog_admission_test.go`）は、この分類を例外として扱う。
4. **この判断で変わるカタログ**（実装は waired-ai/waired#1427）:
   - `glm-5.2` と `deepseek-v4-flash` は後継なしで退役する。
     - glm-5.2 には、参照機に載る variant が無い（最小の GGUF で 211 GB）。
     - deepseek-v4-flash で参照機に載るのは、枝刈り版だけ。
     - 退役表で glm-5.2 を後継にしていた 2 行は、`qwen3.8-27b` に付け替える（連鎖の禁止）。
   - Laguna S 2.1 と Ling-3.0-flash を足す。Laguna は ollama で取り込める 1 ファイルのタグを、参照機で確かめてから入れる。
   - Step-3.7-Flash は見送る。参照機に載る量子化は分割ファイルしか無く、Hugging Face は分割 GGUF を ollama に渡さない。ollama のタグも無い。
5. **YaRN で 1M まで広げられるモデル**（既存の Qwen を含む）は、1M を選んだときに警告を出したうえで出す。設計と実装は waired-ai/waired#1456 で扱い、この記録では決めない。

## Consequences

- カタログから、1M ネイティブのモデルが無くなる。
  - 1M のコンテキストウィンドウの定数と、ワイヤや経路の 1M は残る。
  - 1M を宣言するモデルは、#1456 の YaRN で戻る。
  - `proto/hostfit/serving_window_test.go` は、1M に届くモデルが出荷カタログにあることを求めなくなった。
- 量子化していない variant の秒数は、実測ではない。参照機の上に、それを載せられるホストはまだ無い。
