# ストリーム retry (#458) 後にカタログを再測定する (20260803 17:05)

## Status
Accepted

## Context

`internal/catalog/agentgrade.json` の verdict は全て #458 より前に測ったもの
だった（#446、gateway `9200fbeb2d90`）。#458 は、エンジンがターンを配れなかった
とき —— パーサが 500 を上げるか、ストリームが無言で切れるか —— に gateway が
再生成するようにした。**verdict が測っているのは「コーディングエージェントが
実際に受け取るもの」なので、これは答えを変える変更**であり、実際に変えた。

`fixture_revision` は gateway を含まない。世代を見分けられるのは
`agent_revision` だけで、それは #434 がまさにこの理由で入れたフィールドである。

再測定の条件:

- 17 variant（提示対象 16 + internal の granite4-350m）
- 各モデルを unary と stream の両方で 12 試行ずつ、**合算 24**
- engine ollama 0.31.1（pin 版）、fixture `2004661dc908`、
  agent **`225364f4f522`**、24 GB discrete NVIDIA
- 測定は編集しない専用ワークツリーから実行（make target は追跡ファイルの変更
  ひとつで `-dirty` を刻み、`-dirty` なレポートは import できない）

## Decision

**17 variant すべてを #458 後の 1 世代で置き換える。**

### 動いた向きが失敗の種類と一致している

`malformed`（エンジンのパーサが 500 を上げる、ollama/ollama#16383）を主因と
する 3 件は揃って下がった —— 9b が 11→3、4b が 6→1、35b-a3b が 5→2。
`no_tool_call` / `unstructured`（モデルが地の文で答えてしまう）を主因とする
ものは下がらず、むしろ上がったものもある（3b 7→12、granite4 8→11）。後者は
素の揺らぎで、**#458 が狙ったクラスだけを消していることの実測上の裏付け**に
なっている。

**qwen2.5-coder:0.5b は 48/72 のまま 1 も動かなかった。** 前後で完全に同一。
その「tool call」はデーモン名とファイルパスを名乗る地の文で、gateway は提示
されていない名前を回収しないため 200 が返り、retry の条件に当たらない。

### 記録するのは gateway 越しの数字であって、素の失敗率ではない

9b の素のパース失敗は消えていない。実測ログでは 72 ターン中 8 ターンが retry を
経由しており（うち 1 ターンは 2 回）、**モデルは「壊れる」から「遅い」に変わった**。
verdict はその区別を表現できない。それでよい —— このプローブは「コーディング
エージェントが受け取るもの」を測ると宣言しており、素のエンジンを単独で測るのは
誰も話しかけない対象を測ることになる（`internal/e2e/agentgrade` 冒頭）。
レイテンシは boot benchmark の担当。

## Consequences

- **退役ワークリストは `qwen2.5-coder-0.5b-instruct` 1 件のまま。** #462 の
  ゴールデンテストがこれを固定しており、データ差し替えでも動かなかった。
- **閾値 0.5 の根拠はむしろ強くなった。** 0.5b の下限 0.899 と、その次点の
  間の空白が **0.304（9b）→ 0.233（3b）** に下がり、余裕が 3 倍から 3.9 倍に
  広がった。
- **`0/72` は運も入っていた。** qwen2.5-coder:7b —— コンパイル時の
  `BundledModelID` —— が 0→2 に動いた。下限 0.009 で実害はないが、
  **n=24 の全問正解が証明するのは「10% 未満」までで、それ以上ではない**。
  信頼下限で線を引く理由がそのまま出ている。
- **インストール品質フロアを定義する qwen2.5-coder:3b の下限がほぼ倍増した**
  （0.167 → 0.233、search-then-edit 9/24）。退役線からは遠いが、フロアの
  モデルが二段階ツール要求の 4 回に 1 回近くを落とすことは #200 の判断材料。
- 提示側の是非には触れない。qwen3.5:0.8b は 3/72（下限 0.028）で
  **agent-grade では落ちない** —— 提示をやめる理由があるとすれば tier 12 と
  停止性の欠陥（1 語のプロンプトに 17,787 トークン、
  `20260801/1900-ci-fixture-model-withheld.md`）であって、agent-grade ではない。
- `--require-pass` は引き続き無効のまま（`20260803/1454-...` の判断どおり）。
